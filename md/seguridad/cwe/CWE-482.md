# CWE-482: Comparing instead of Assigning

**Tipo de fallo de software CWE-482** (Variant).

The code uses an operator for comparison when the intention was to perform an assignment.

- **Es un caso de:** [CWE-480](/seguridad/cwe/CWE-480.md)

## Consecuencias

- Unexpected State: The assignment will not take place, which should cause obvious program execution problems.

## Cómo evitarlo

- Many IDEs and static analysis products will detect this problem.
