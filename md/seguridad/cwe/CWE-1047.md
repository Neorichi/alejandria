# CWE-1047: Modules with Circular Dependencies

**Tipo de fallo de software CWE-1047** (Base).

The product contains modules in which one module has references that cycle back to itself, i.e., there are circular dependencies.

As an example, with Java, this weakness might indicate cycles between packages.

- **Es un caso de:** [CWE-1120](/seguridad/cwe/CWE-1120.md)

## Consecuencias

- Reduce Maintainability: This issue makes it more difficult to maintain the product due to insufficient modularity, which indirectly affects security by making it more difficult or time-consuming to find and/or fix vulnerabilities. It can also prevent the product from running reliably. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
