# CWE-672: Operation on a Resource after Expiration or Release

**Tipo de fallo de software CWE-672** (Class).

The product uses, accesses, or otherwise operates on a resource after that resource has been expired, released, or revoked.

- **Es un caso de:** [CWE-666](/seguridad/cwe/CWE-666.md)

## Consecuencias

- Modify Application Data: If a released resource is subsequently reused or reallocated, then an attempt to use the original resource might allow access to sensitive data that is associated with a different user or entity.
- Other: When a resource is released it might not be in an expected state, later attempts to access the resource may lead to resultant errors that may lead to a crash.
