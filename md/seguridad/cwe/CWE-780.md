# CWE-780: Use of RSA Algorithm without OAEP

**Tipo de fallo de software CWE-780** (Variant).

The product uses the RSA algorithm but does not incorporate Optimal Asymmetric Encryption Padding (OAEP).

- **Es un caso de:** [CWE-327](/seguridad/cwe/CWE-327.md)

## Consecuencias

- Bypass Protection Mechanism: Without using OAEP, this might weaken the encryption. It will take less work for an attacker to decrypt the data or to infer patterns from the ciphertext.
