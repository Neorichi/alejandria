# S0624 Ecipekac (Malware)

**Malware de MITRE ATT&CK** S0624.

- **Plataformas:** Windows

Ecipekac is a multi-layer loader that has been used by menuPass since at least 2019 including use as a loader for P8RAT, SodaMaster, and FYAnti.
