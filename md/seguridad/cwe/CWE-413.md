# CWE-413: Improper Resource Locking

**Tipo de fallo de software CWE-413** (Base).

The product must have exclusive access to a resource, but it does not lock or does not correctly lock that resource.

- **Es un caso de:** [CWE-667](/seguridad/cwe/CWE-667.md)

## Consecuencias

- Modify Application Data: When a resource is not properly locked, an attacker could modify the resource while it is being operated on by the product. This might violate the product's assumption that the resource will not change, potentially leading to unexpected behaviors.

## Cómo evitarlo

- Use a non-conflicting privilege scheme.
- Use synchronization when locking a resource.
