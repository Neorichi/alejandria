# CWE-652: Improper Neutralization of Data within XQuery Expressions

**Tipo de fallo de software CWE-652** (Base).

The product uses external input to dynamically construct an XQuery expression used to retrieve data from an XML database, but it does not neutralize or incorrectly neutralizes that input.

- **Es un caso de:** [CWE-943](/seguridad/cwe/CWE-943.md), [CWE-91](/seguridad/cwe/CWE-91.md)

## Consecuencias

- Read Application Data: An attacker could modify the structure of the query to control what information is selected by the XML database, then use that ability to control application flow, modify logic, retrieve unauthorized data, or bypass important checks (e.g. authentication).

## Cómo evitarlo

- Use parameterized queries. This will help ensure separation between data plane and control plane.
- Properly validate user input. Reject data where appropriate, filter where appropriate and escape where appropriate. Make sure input that will be used in XQL queries is safe in that context.
