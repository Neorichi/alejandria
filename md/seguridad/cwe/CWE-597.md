# CWE-597: Use of Wrong Operator in String Comparison

**Tipo de fallo de software CWE-597** (Variant).

The product uses the wrong operator when comparing a string, such as using "==" when the .equals() method should be used instead.

- **Es un caso de:** [CWE-595](/seguridad/cwe/CWE-595.md), [CWE-480](/seguridad/cwe/CWE-480.md)

## Consecuencias

- Varies by Context: While this weakness often only affects program correctness, if the equality is used for a security decision, the unintended comparison result could be leveraged to affect program security.

## Cómo evitarlo

- Within Java, use .equals() to compare string values. Within JavaScript, use == to compare string values. Within PHP, use == to compare a numeric value to a string value. (PHP converts the string to a number.)
