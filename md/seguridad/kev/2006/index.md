# Vulnerabilidades explotadas (CISA KEV) · 2006

* [CVE-2006-1547 · Apache Struts 1: Apache Struts 1 ActionForm Denial-of-Service Vulnerability](CVE-2006-1547.md) - ActionForm in Apache Struts versions before 1.2.9 with BeanUtils 1.7 contains a vulnerability that allows for denial-of-service (DoS).
* [CVE-2006-2492 · Microsoft Word: Microsoft Word Malformed Object Pointer Vulnerability](CVE-2006-2492.md) - Microsoft Word and Microsoft Works Suites contain a malformed object pointer which allows attackers to execute code.
