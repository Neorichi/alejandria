# CWE-581: Object Model Violation: Just One of Equals and Hashcode Defined

**Tipo de fallo de software CWE-581** (Variant).

The product does not maintain equal hashcodes for equal objects.

- **Es un caso de:** [CWE-573](/seguridad/cwe/CWE-573.md), [CWE-697](/seguridad/cwe/CWE-697.md)

## Consecuencias

- Other: If this invariant is not upheld, it is likely to cause trouble if objects of this class are stored in a collection. If the objects of the class in question are used as a key in a Hashtable or if they are inserted into a Map or Set, it is critical that equal objects have equal hashcodes.

## Cómo evitarlo

- Both Equals() and Hashcode() should be defined.
