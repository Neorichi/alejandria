# CWE-1082: Class Instance Self Destruction Control Element

**Tipo de fallo de software CWE-1082** (Base).

The code contains a class instance that calls the method or function to delete or destroy itself, e.g., use of "delete this" in C++.

- **Es un caso de:** [CWE-1076](/seguridad/cwe/CWE-1076.md)

## Consecuencias

- Reduce Reliability: This issue can prevent the product from running reliably. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
