# CWE-1085: Invokable Control Element with Excessive Volume of Commented-out Code

**Tipo de fallo de software CWE-1085** (Base).

A function, method, procedure, etc. contains an excessive amount of code that has been commented out within its body.

- **Es un caso de:** [CWE-1078](/seguridad/cwe/CWE-1078.md)

## Consecuencias

- Reduce Maintainability: This issue makes it more difficult to maintain the product, which indirectly affects security by making it more difficult or time-consuming to find and/or fix vulnerabilities. It also might make it easier to introduce vulnerabilities.
