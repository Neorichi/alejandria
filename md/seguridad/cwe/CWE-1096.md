# CWE-1096: Singleton Class Instance Creation without Proper Locking or Synchronization

**Tipo de fallo de software CWE-1096** (Variant).

The product implements a Singleton design pattern but does not use appropriate locking or other synchronization mechanism to ensure that the singleton class is only instantiated once.

- **Es un caso de:** [CWE-820](/seguridad/cwe/CWE-820.md), [CWE-662](/seguridad/cwe/CWE-662.md)

## Consecuencias

- Reduce Reliability: This issue can prevent the product from running reliably, e.g. by making the instantiation process non-thread-safe and introducing deadlock (CWE-833) or livelock conditions. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
