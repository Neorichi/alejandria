# CWE-835: Loop with Unreachable Exit Condition

**Tipo de fallo de software CWE-835** (Base).

The product contains an iteration or loop with an exit condition that cannot be reached, i.e., an infinite loop.

- **Es un caso de:** [CWE-834](/seguridad/cwe/CWE-834.md)

## Consecuencias

- DoS: Resource Consumption (CPU): An infinite loop will cause unexpected consumption of resources, such as CPU cycles or memory. The software's operation may slow down, or cause a long time to respond.
