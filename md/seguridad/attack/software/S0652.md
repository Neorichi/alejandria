# S0652 MarkiRAT (Malware)

**Malware de MITRE ATT&CK** S0652.

- **Plataformas:** Windows

MarkiRAT is a remote access Trojan (RAT) compiled with Visual Studio that has been used by Ferocious Kitten since at least 2015.
