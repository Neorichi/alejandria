# CWE-459: Incomplete Cleanup

**Tipo de fallo de software CWE-459** (Base).

The product does not properly "clean up" and remove temporary or supporting resources after they have been used.

- **Es un caso de:** [CWE-404](/seguridad/cwe/CWE-404.md)

## Consecuencias

- Other: It is possible to overflow the number of temporary files because directories typically have limits on the number of files allowed. This could create a denial of service problem.

## Cómo evitarlo

- Temporary files and other supporting resources should be deleted/released immediately after they are no longer needed.
