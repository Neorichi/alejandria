# Nitrosomonadales

- **Name:** Nitrosomonadales
- **Domain:** Bacteria
- **Regnum:** Pseudomonadati
- **Phylum:** Pseudomonadota
- **Classis:** Betaproteobacteria
- **Ordo:** Nitrosomonadales
- **Subdivision ranks:** Familias y géneros
- **Subdivision:** Nitrosomonadaceae Nitrosomonas Nitrosospira Nitrosovibrio Spirillaceae Spirillum

**Nitrosomonadales** es un pequeño orden de Proteobacteria.  Incluye los géneros *Nitrosomonas*, *Nitrosospira* y *Spirillum*.
