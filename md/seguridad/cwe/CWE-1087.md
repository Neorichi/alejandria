# CWE-1087: Class with Virtual Method without a Virtual Destructor

**Tipo de fallo de software CWE-1087** (Base).

A class contains a virtual method, but the method does not have an associated virtual destructor.

- **Es un caso de:** [CWE-1076](/seguridad/cwe/CWE-1076.md)

## Consecuencias

- Reduce Reliability: This issue can prevent the product from running reliably, e.g. due to undefined behavior. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
