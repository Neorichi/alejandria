# CWE-318: Cleartext Storage of Sensitive Information in Executable

**Tipo de fallo de software CWE-318** (Variant).

The product stores sensitive information in cleartext in an executable.

- **Es un caso de:** [CWE-312](/seguridad/cwe/CWE-312.md)

## Consecuencias

- Read Application Data: Attackers can reverse engineer binary code to obtain secret data. This is especially easy when the cleartext is plain ASCII. Even if the information is encoded in a way that is not human-readable, certain techniques could determine which encoding is being used, then decode the information.
