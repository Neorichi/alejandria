# CWE-572: Call to Thread run() instead of start()

**Tipo de fallo de software CWE-572** (Variant).

The product calls a thread's run() method instead of calling start().

- **Es un caso de:** [CWE-821](/seguridad/cwe/CWE-821.md)

## Consecuencias

- Quality Degradation: The run() method will execute in the caller's thread of control, when the intention was likely to run in the thread of the callee.

## Cómo evitarlo

- Use the start() method instead of the run() method.
