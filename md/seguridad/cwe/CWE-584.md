# CWE-584: Return Inside Finally Block

**Tipo de fallo de software CWE-584** (Base).

The code has a return statement inside a finally block.

- **Es un caso de:** [CWE-705](/seguridad/cwe/CWE-705.md)

## Consecuencias

- Alter Execution Logic: With some languages, this will cause any thrown exception in the try block to be discarded.

## Cómo evitarlo

- Do not use a return statement inside the finally block. The finally block should have "cleanup" code.
