# CWE-587: Assignment of a Fixed Address to a Pointer

**Tipo de fallo de software CWE-587** (Variant).

The product sets a pointer to a specific address other than NULL or 0.

- **Es un caso de:** [CWE-344](/seguridad/cwe/CWE-344.md), [CWE-758](/seguridad/cwe/CWE-758.md)

## Consecuencias

- Execute Unauthorized Code or Commands: If one executes code at a known location, an attacker might be able to inject code there beforehand.
- DoS: Crash, Exit, or Restart: If the code is ported to another platform or environment, the pointer is likely to be invalid and cause a crash.
- Read Memory: The data at a known pointer location can be easily read or influenced by an attacker.

## Cómo evitarlo

- Never set a pointer to a fixed address.
