# S1076 QUIETCANARY (Malware)

**Malware de MITRE ATT&CK** S1076.

- **Plataformas:** Windows

QUIETCANARY is a backdoor tool written in .NET that has been used since at least 2022 to gather and exfiltrate data from victim networks.
