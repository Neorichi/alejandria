# CWE-1088: Synchronous Access of Remote Resource without Timeout

**Tipo de fallo de software CWE-1088** (Base).

The code has a synchronous call to a remote resource, but there is no timeout for the call, or the timeout is set to infinite.

- **Es un caso de:** [CWE-821](/seguridad/cwe/CWE-821.md)

## Consecuencias

- Reduce Reliability: This issue can prevent the product from running reliably, since an outage for the remote resource can cause the product to hang. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
