# CWE-1062: Parent Class with References to Child Class

**Tipo de fallo de software CWE-1062** (Base).

The code has a parent class that contains references to a child class, its methods, or its members.

- **Es un caso de:** [CWE-1061](/seguridad/cwe/CWE-1061.md)

## Consecuencias

- Reduce Reliability: This issue can prevent the product from running reliably. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
