# CWE-1023: Incomplete Comparison with Missing Factors

**Tipo de fallo de software CWE-1023** (Class).

The product performs a comparison between entities that must consider multiple factors or characteristics of each entity, but the comparison does not include one or more of these factors.

- **Es un caso de:** [CWE-697](/seguridad/cwe/CWE-697.md)

## Consecuencias

- Alter Execution Logic: An incomplete comparison can lead to resultant weaknesses, e.g., by operating on the wrong object or making a security decision without considering a required factor.
