# CWE-674: Uncontrolled Recursion

**Tipo de fallo de software CWE-674** (Class).

The product does not properly control the amount of recursion that takes place, consuming excessive resources, such as allocated memory or the program stack.

- **Es un caso de:** [CWE-834](/seguridad/cwe/CWE-834.md)

## Consecuencias

- DoS: Resource Consumption (CPU): Resources including CPU, memory, and stack memory could be rapidly consumed or exhausted, eventually leading to an exit or crash.
- Read Application Data: In some cases, an application's interpreter might kill a process or thread that appears to be consuming too many resources, such as with PHP's memory_limit setting. When the interpreter kills the process/thread, it might report an error containing detailed information such as the application's installation path.

## Cómo evitarlo

- Ensure that an end condition will be reached under all logic conditions. The end condition may include checking against the depth of recursion and exiting with an error if the recursion goes too deep. The complexity of the end condition contributes to the effectiveness of this action.
- Increase the stack size.
