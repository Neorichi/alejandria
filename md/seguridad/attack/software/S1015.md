# S1015 Milan (Malware)

**Malware de MITRE ATT&CK** S1015.

- **Plataformas:** Windows

Milan is a backdoor implant based on DanBot that was written in Visual C++ and .NET. Milan has been used by HEXANE since at least June 2020.
