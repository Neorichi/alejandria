# CWE-910: Use of Expired File Descriptor

**Tipo de fallo de software CWE-910** (Base).

The product uses or accesses a file descriptor after it has been closed.

- **Es un caso de:** [CWE-672](/seguridad/cwe/CWE-672.md)

## Consecuencias

- Read Files or Directories: The reused file descriptor might reference a different file or device than the original file descriptor. As a result, the program could read data from, or write data to, the wrong file.
- DoS: Crash, Exit, or Restart: Accessing a file descriptor that has been closed can cause a crash.
