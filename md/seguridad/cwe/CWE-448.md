# CWE-448: Obsolete Feature in UI

**Tipo de fallo de software CWE-448** (Base).

A UI function is obsolete and the product does not warn the user.

- **Es un caso de:** [CWE-446](/seguridad/cwe/CWE-446.md)

## Consecuencias

- Quality Degradation

## Cómo evitarlo

- Remove the obsolete feature from the UI. Warn the user that the feature is no longer supported.
