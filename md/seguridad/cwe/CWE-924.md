# CWE-924: Improper Enforcement of Message Integrity During Transmission in a Communication Channel

**Tipo de fallo de software CWE-924** (Base).

The product establishes a communication channel with an endpoint and receives a message from that endpoint, but it does not sufficiently ensure that the message was not modified during transmission.

- **Es un caso de:** [CWE-345](/seguridad/cwe/CWE-345.md)

## Consecuencias

- Gain Privileges or Assume Identity: Attackers might be able to modify the message and spoof the endpoint by interfering with the data as it crosses the network or by redirecting the connection to a system under their control. If an attacker can spoof the endpoint, they might gain all the privileges that were intended for the original endpoint.
