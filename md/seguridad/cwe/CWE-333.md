# CWE-333: Improper Handling of Insufficient Entropy in TRNG

**Tipo de fallo de software CWE-333** (Variant).

True random number generators (TRNG) generally have a limited source of entropy and therefore can fail or block.

- **Es un caso de:** [CWE-331](/seguridad/cwe/CWE-331.md), [CWE-755](/seguridad/cwe/CWE-755.md)

## Consecuencias

- DoS: Crash, Exit, or Restart: A program may crash or block if it runs out of random numbers.

## Cómo evitarlo

- Since the rate at which true random numbers can be generated is limited, it is important that one uses them only when they are needed for security.
- Rather than failing on a lack of random numbers, it is often preferable to wait for more numbers to be created.
