# CWE-1351: Improper Handling of Hardware Behavior in Exceptionally Cold Environments

**Tipo de fallo de software CWE-1351** (Base).

The hardware device, or the firmware running on it, is missing or has incorrect protection mechanisms to maintain goals of security primitives when the device is cooled below standard operating temperatures.

- **Es un caso de:** [CWE-1384](/seguridad/cwe/CWE-1384.md)

## Consecuencias

- Varies by Context: This may result in a weakness when the starting state of the volatile memory is being relied upon for a security decision. Consequences of this weakness are highly contextual.

## Cómo evitarlo

- The system should account for security primitive behavior when cooled outside standard temperatures.
