# CWE-483: Incorrect Block Delimitation

**Tipo de fallo de software CWE-483** (Base).

The code does not explicitly delimit a block that is intended to contain 2 or more statements.

- **Es un caso de:** [CWE-670](/seguridad/cwe/CWE-670.md)

## Consecuencias

- Alter Execution Logic: This is a general logic error that will often lead to obviously-incorrect behaviors that are quickly noticed and fixed. In lightly tested or untested code, this error may be introduced it into a production environment and provide additional attack vectors by creating a control flow path leading to an unexpected state in the application. The consequences will depend on the types of behaviors that are being incorrectly executed.

## Cómo evitarlo

- Always use explicit block delimitation and use static-analysis technologies to enforce this practice.
