# CWE-1127: Compilation with Insufficient Warnings or Errors

**Tipo de fallo de software CWE-1127** (Class).

The code is compiled without sufficient warnings enabled.

- **Es un caso de:** [CWE-710](/seguridad/cwe/CWE-710.md)

## Consecuencias

- Reduce Maintainability: This issue makes it more difficult to maintain the product, which indirectly affects security by making it more difficult or time-consuming to find and/or fix vulnerabilities. It also might make it easier to introduce vulnerabilities.
- Increase Analytical Complexity: This issue may prevent the detection of subtle bugs or quality issues.

## Cómo evitarlo

- Compile the code with the best options available to generate the most warnings that are actionable.
