# Ipratropio/salbutamol

- **Verifiedrevid:** 400118589
- **Type:** combo
- **Component1:** Ipratropium bromide
- **Class1:** Muscarinic antagonist
- **Component2:** Salbutamol
- **Class2:** Short-acting β2-adrenergic agonist
- **Tradename:** Combivent, DuoNeb, Breva, others
- **Pregnancy us:** C
- **Routes of administration:** Inhalation
- **Medlineplus:** a601063

El **ipratropio/salbutamol**, es vendido bajo la marca Combivent, entre otras, es un medicamento combinado que se utiliza para tratar la enfermedad pulmonar obstructiva crónica. Contiene ipratropio (un anticolinérgico ) y salbutamol. Este medicamento se toma por inhalación.

Los efectos secundarios de este medicamento  incluyen dolor de garganta, calambres musculares y náuseas. Otros efectos secundarios pueden incluir broncoespasmo, reacciones alérgicas e infecciones de las vías respiratorias superiores. La seguridad de este medicamento durante el embarazo no está clara. Cada medicamento generalmente disminuye el broncoespasmo y lo hace a través de diferentes mecanismos.

Este medicamento fue aprobada para uso médico en los Estados Unidos en 1996. Está disponible como medicamento genérico. Sesenta dosis en el Reino Unido le cuestan al NHS alrededor de 18 libras esterlinas  a partir de 2019. En Estados Unidos, el costo mayorista de esta cantidad es de aproximadamente 9.50 dólares estadounidenses. En 2017, fue el medicamento número 172 más recetado en Estados Unidos, con más de tres millones de recetas.
