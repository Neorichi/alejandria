# CWE-836: Use of Password Hash Instead of Password for Authentication

**Tipo de fallo de software CWE-836** (Base).

The product includes a client that computes a hash of a password and sends the hash to another component, which compares the supplied hash to the hash obtained from a data store of password hashes.

- **Es un caso de:** [CWE-1390](/seguridad/cwe/CWE-1390.md)

## Consecuencias

- Bypass Protection Mechanism: An attacker could bypass the authentication routine without knowing the original password. The attacker could obtain a copy of the hash (e.g., through a separate weakness against a database of authentication credentials), then use a modified client to replay the stolen hash. As a result, the server-side comparison against a client-side hash does not provide any more security than the use of passwords without hashing.
