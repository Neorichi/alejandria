# CWE-462: Duplicate Key in Associative List (Alist)

**Tipo de fallo de software CWE-462** (Variant).

Duplicate keys in associative lists can lead to non-unique keys being mistaken for an error.

- **Es un caso de:** [CWE-694](/seguridad/cwe/CWE-694.md)

## Consecuencias

- Quality Degradation: If an alist contains duplicate key entries, this introduces an ambiguity in which it cannot be predicted which key value will be selected.

## Cómo evitarlo

- Use a hash table instead of an alist.
- Use an alist which checks the uniqueness of hash keys with each entry before inserting the entry.
- Duplicate key entries in an association list are not recommended and should not be allowed.
