# S1116 WARPWIRE (Malware)

**Malware de MITRE ATT&CK** S1116.

- **Plataformas:** Network Devices

WARPWIRE is a Javascript credential stealer that targets plaintext passwords and usernames for exfiltration that was used during Cutting Edge to target Ivanti Connect Secure VPNs.
