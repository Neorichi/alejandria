# S0226 Smoke Loader (Malware)

**Malware de MITRE ATT&CK** S0226.

- **Plataformas:** Windows

Smoke Loader is a malicious bot application that can be used to load other malware.
Smoke Loader has been seen in the wild since at least 2011 and has included a number of different payloads. It is notorious for its use of deception and self-protection. It also comes with several plug-ins.
