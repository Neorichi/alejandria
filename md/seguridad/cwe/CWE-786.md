# CWE-786: Access of Memory Location Before Start of Buffer

**Tipo de fallo de software CWE-786** (Base).

The product reads or writes to a buffer using an index or pointer that references a memory location prior to the beginning of the buffer.

- **Es un caso de:** [CWE-119](/seguridad/cwe/CWE-119.md)

## Consecuencias

- Read Memory: For an out-of-bounds read, the attacker may have access to sensitive information. If the sensitive information contains system details, such as the current buffer's position in memory, this knowledge can be used to craft further attacks, possibly with more severe consequences.
- Modify Memory: Out of bounds memory access will very likely result in the corruption of relevant memory, and perhaps instructions, possibly leading to a crash.
- Modify Memory: If the corrupted memory can be effectively controlled, it may be possible to execute arbitrary code. If the corrupted memory is data rather than instructions, the system will continue to function with improper changes, possibly in violation of an implicit or explicit policy.
