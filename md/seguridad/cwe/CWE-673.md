# CWE-673: External Influence of Sphere Definition

**Tipo de fallo de software CWE-673** (Class).

The product does not prevent the definition of control spheres from external actors.

Typically, a product defines its control sphere within the code itself, or through configuration by the product's administrator. In some cases, an external party can change the definition of the control sphere.
