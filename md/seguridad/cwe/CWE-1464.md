# CWE-1464: Improper Session Invalidation

**Tipo de fallo de software CWE-1464** (Base).

The product establishes a session for an authenticated user, but it does not properly invalidate or terminate the session when it is required.

- **Es un caso de:** [CWE-1462](/seguridad/cwe/CWE-1462.md)

## Cómo evitarlo

- Ensure that user sessions are invalidated on the server-side for all possible security related events relevant to the application. It is important that the server-side handles all session invalidation and does not rely on the client to remove or delete a session, due to the possibility of adversaries capturing session identifiers or cookies for later reuse.
