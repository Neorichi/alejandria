# Problemas respiratorios

- **También se llama:** Disnea, Problemas para respirar
- **Grupo:** Pulmón y vías respiratorias, Síntomas

Cuando usted tiene problemas para respirar, le cuesta o es incómodo obtener el oxígeno que necesita. Puede sentir que no está obteniendo el suficiente aire. A veces puede tener problemas respiratorios leves por una congestión nasal o hacer ejercicio muy intensamente. Pero la falta de aire también puede ser señal de una enfermedad seria.

Muchas condiciones pueden hacer sentir que le falta el aire:

- Problemas de los pulmones como [asma](/medicina/medlineplus/a/asma.md), [enfisema](/medicina/medlineplus/e/enfisema.md) o [neumonía](/medicina/medlineplus/n/neumonia.md)

- Problemas de su [tráquea](/medicina/medlineplus/e/enfermedades-de-la-traquea.md) o en los [bronquios](/medicina/medlineplus/t/trastornos-de-los-bronquios.md), que son parte de su sistema respiratorio

- Las [enfermedades cardíacas](/medicina/medlineplus/e/enfermedades-del-corazon.md) pueden provocar falta de aire si su corazón no puede bombear suficiente sangre para suministrarle oxígeno al cuerpo

- [Ansiedad](/medicina/medlineplus/a/ansiedad.md) o [ataque de pánico](/medicina/medlineplus/t/trastorno-de-panico.md)

- [Alergias](/medicina/medlineplus/a/alergia.md)

Si usted tiene problemas para respirar en forma frecuente, es importante encontrar la causa.
