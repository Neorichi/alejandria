# CWE-343: Predictable Value Range from Previous Values

**Tipo de fallo de software CWE-343** (Base).

The product's random number generator produces a series of values which, when observed, can be used to infer a relatively small range of possibilities for the next value that could be generated.

- **Es un caso de:** [CWE-340](/seguridad/cwe/CWE-340.md)

## Consecuencias

- Varies by Context: In some cases, an attacker cannot predict the exact value that will be produced next, but can narrow down the possibilities significantly. This reduces the amount of effort to perform a brute force attack.

## Cómo evitarlo

- The output of a random number generator should not be predictable based on observations of previous values.
- Increase the entropy used to seed a PRNG.
- Use products or modules that conform to FIPS 140-2 [REF-267] to avoid obvious entropy problems. Consult FIPS 140-2 Annex C ("Approved Random Number Generators").
- Use a PRNG that periodically re-seeds itself using input from high-quality sources, such as hardware devices with high entropy. However, do not re-seed too frequently, or else the entropy source might block.
