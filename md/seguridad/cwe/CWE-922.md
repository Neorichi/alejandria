# CWE-922: Insecure Storage of Sensitive Information

**Tipo de fallo de software CWE-922** (Class).

The product stores sensitive information without properly limiting read or write access by unauthorized actors.

- **Es un caso de:** [CWE-664](/seguridad/cwe/CWE-664.md)

## Consecuencias

- Read Application Data: Attackers can read sensitive information by accessing the unrestricted storage mechanism.
- Modify Application Data: Attackers can overwrite and possibly delete sensitive information by accessing the unrestricted storage mechanism, causing incorrect results and possibly a denial of service.
