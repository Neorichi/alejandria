# CWE-1078: Inappropriate Source Code Style or Formatting

**Tipo de fallo de software CWE-1078** (Class).

The source code does not follow desired style or formatting for indentation, white space, comments, etc.

- **Es un caso de:** [CWE-1076](/seguridad/cwe/CWE-1076.md)

## Consecuencias

- Increase Analytical Complexity: Variations in indentation and other white space, comments, etc. can make it more difficult for human analysts to understand the actual behavior that is being implemented.
