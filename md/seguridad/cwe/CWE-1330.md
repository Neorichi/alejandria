# CWE-1330: Remanent Data Readable after Memory Erase

**Tipo de fallo de software CWE-1330** (Variant).

Confidential information stored in memory circuits is readable or recoverable after being cleared or erased, i.e., there is data remanence.

- **Es un caso de:** [CWE-1301](/seguridad/cwe/CWE-1301.md)

## Consecuencias

- Modify Memory: Data remanence occurs when stored memory content is not fully lost after a memory-clear or memory-erase operation. Confidential memory contents can still be readable through data remanence in the hardware. Confidential data are readable to untrusted agent.

## Cómo evitarlo

- Support for secure-erase commands that apply multiple cycles of overwriting memory with known patterns and of erasing actual content. Support for cryptographic erase in self-encrypting, memory devices. External, physical tools to erase memory such as ultraviolet-rays-based erase of Electrically erasable, programmable, read-only memory (EEPROM). Physical destruction of media device. This is done for repurposed or scrapped devices that are no longer in use.
