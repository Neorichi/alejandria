# Giro temporal medio

- **Nombre:** Giro temporal medio
- **Ta:** A14.1.09.146
- **Sinónimos:** circunvolución temporal mediasegunda circunvolución temporal (T2)

El **giro temporal medio** es una circunvolución del cerebro. Es la segunda circunvolución temporal
(T2), comprendida entre los dos surcos temporales y, se continúa por detrás con el pliegue curvo.
