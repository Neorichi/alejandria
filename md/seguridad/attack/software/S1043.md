# S1043 ccf32 (Malware)

**Malware de MITRE ATT&CK** S1043.

- **Plataformas:** Windows

ccf32 is data collection malware that has been used since at least February 2019, most notably during the FunnyDream campaign; there is also a similar x64 version.
