# CWE-446: UI Discrepancy for Security Feature

**Tipo de fallo de software CWE-446** (Class).

The user interface does not correctly enable or configure a security feature, but the interface provides feedback that causes the user to believe that the feature is in a secure state.

- **Es un caso de:** [CWE-684](/seguridad/cwe/CWE-684.md)

## Consecuencias

- Varies by Context: When the user interface does not properly reflect what the user asks of it, then it can lead the user into a false sense of security.
