# CWE-460: Improper Cleanup on Thrown Exception

**Tipo de fallo de software CWE-460** (Base).

The product does not clean up its state or incorrectly cleans up its state when an exception is thrown.

- **Es un caso de:** [CWE-459](/seguridad/cwe/CWE-459.md), [CWE-755](/seguridad/cwe/CWE-755.md)

## Consecuencias

- Unexpected State: Exceptions can disturb the flow of the code and prevent the necessary cleanup from happening. This could lead to unexpected state or control flow.

## Cómo evitarlo

- If one breaks from a loop or function by throwing an exception, make sure that cleanup happens or that you should exit the program. Use throwing exceptions sparsely.
