# S0229 Orz (Malware)

**Malware de MITRE ATT&CK** S0229.

- **Plataformas:** Windows

Orz is a custom JavaScript backdoor used by Leviathan. It was observed being used in 2014 as well as in August 2017 when it was dropped by Microsoft Publisher files.
