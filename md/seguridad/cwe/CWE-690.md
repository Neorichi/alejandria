# CWE-690: Unchecked Return Value to NULL Pointer Dereference

**Tipo de fallo de software CWE-690** (Compound).

The product does not check for an error after calling a function that can return with a NULL pointer if the function fails, which leads to a resultant NULL pointer dereference.

- **Es un caso de:** [CWE-252](/seguridad/cwe/CWE-252.md)

## Consecuencias

- DoS: Crash, Exit, or Restart
- Execute Unauthorized Code or Commands: In rare circumstances, when NULL is equivalent to the 0x0 memory address and privileged code can access it, then writing or reading memory is possible, which may lead to code execution.
