# CWE-837: Improper Enforcement of a Single, Unique Action

**Tipo de fallo de software CWE-837** (Base).

The product requires that an actor should only be able to perform an action once, or to have only one unique action, but the product does not enforce or incorrectly enforces this restriction.

- **Es un caso de:** [CWE-799](/seguridad/cwe/CWE-799.md)

## Consecuencias

- Varies by Context: An attacker might be able to gain advantage over other users by performing the action multiple times, or affect the correctness of the product.
