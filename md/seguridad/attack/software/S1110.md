# S1110 SLIGHTPULSE (Malware)

**Malware de MITRE ATT&CK** S1110.

- **Plataformas:** Network Devices, Linux

SLIGHTPULSE is a web shell that was used by APT5 as early as 2020 including against Pulse Secure VPNs at US Defense Industrial Base (DIB) entities.
