# CWE-912: Hidden Functionality

**Tipo de fallo de software CWE-912** (Class).

The product contains functionality that is not documented, not part of the specification, and not accessible through an interface or command sequence that is obvious to the product's users or administrators.

- **Es un caso de:** [CWE-684](/seguridad/cwe/CWE-684.md)

## Consecuencias

- Varies by Context: From a security perspective, even when the functionality is not intentionally malicious or damaging, it can increase the product's attack surface and expose additional weaknesses beyond what is already exposed by the intended functionality. Even if it is not easily accessible, the hidden functionality could be useful for attacks that modify the control flow of the application.

## Cómo evitarlo

- Always verify the integrity of the product that is being installed.
