# CWE-317: Cleartext Storage of Sensitive Information in GUI

**Tipo de fallo de software CWE-317** (Variant).

The product stores sensitive information in cleartext within the GUI.

- **Es un caso de:** [CWE-312](/seguridad/cwe/CWE-312.md)

## Consecuencias

- Read Memory: An attacker can often obtain data from a GUI, even if hidden, by using an API to directly access GUI objects such as windows and menus. Even if the information is encoded in a way that is not human-readable, certain techniques could determine which encoding is being used, then decode the information.
