# S0559 SUNBURST (Malware)

**Malware de MITRE ATT&CK** S0559.

- **Plataformas:** Windows

SUNBURST is a trojanized DLL designed to fit within the SolarWinds Orion software update framework. It was used by APT29 since at least February 2020.
