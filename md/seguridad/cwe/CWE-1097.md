# CWE-1097: Persistent Storable Data Element without Associated Comparison Control Element

**Tipo de fallo de software CWE-1097** (Base).

The product uses a storable data element that does not have all of the associated functions or methods that are necessary to support comparison.

- **Es un caso de:** [CWE-1076](/seguridad/cwe/CWE-1076.md), [CWE-595](/seguridad/cwe/CWE-595.md)

## Consecuencias

- Reduce Reliability: This issue can prevent the product from running reliably, due to incorrect or unexpected comparison results. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
