# CWE-822: Untrusted Pointer Dereference

**Tipo de fallo de software CWE-822** (Base).

The product obtains a value from an untrusted source, converts this value to a pointer, and dereferences the resulting pointer.

- **Es un caso de:** [CWE-119](/seguridad/cwe/CWE-119.md)

## Consecuencias

- Read Memory: If the dereferencing operation is for a read, then the attack might allow reading of sensitive data, cause a crash, or set a variable to an unexpected value (since the value will be read from an unexpected memory location).
- DoS: Crash, Exit, or Restart: If the untrusted pointer references a memory location that is not accessible to the product, or points to a location that is "malformed" or larger than expected by a read or write operation, the application may terminate unexpectedly.
- Execute Unauthorized Code or Commands: If the pointer is dereferenced for a write operation, the attack might allow modification of critical state variables, cause a crash, or execute code. If the untrusted pointer is used in a function call, then the attacker might be able to call arbitrary functions.
