# CWE-654: Reliance on a Single Factor in a Security Decision

**Tipo de fallo de software CWE-654** (Base).

A protection mechanism relies exclusively, or to a large extent, on the evaluation of a single condition or the integrity of a single object or entity in order to make a decision about granting access to restricted resources or functionality.

- **Es un caso de:** [CWE-657](/seguridad/cwe/CWE-657.md), [CWE-693](/seguridad/cwe/CWE-693.md)

## Consecuencias

- Gain Privileges or Assume Identity: If the single factor is compromised (e.g. by theft or spoofing), then the integrity of the entire security mechanism can be violated with respect to the user that is identified by that factor.
- Hide Activities: It can become difficult or impossible for the product to be able to distinguish between legitimate activities by the entity who provided the factor, versus illegitimate activities by an attacker.

## Cómo evitarlo

- Use multiple simultaneous checks before granting access to critical operations or granting critical privileges. A weaker but helpful mitigation is to use several successive checks (multiple layers of security).
- Use redundant access rules on different choke points (e.g., firewalls).
