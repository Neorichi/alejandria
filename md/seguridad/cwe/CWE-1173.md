# CWE-1173: Improper Use of Validation Framework

**Tipo de fallo de software CWE-1173** (Base).

The product does not use, or incorrectly uses, an input validation framework that is provided by the source language, framework, or an independent library.

- **Es un caso de:** [CWE-20](/seguridad/cwe/CWE-20.md)

## Consecuencias

- Unexpected State: Unchecked input leads to cross-site scripting, process control, and SQL injection vulnerabilities, among others.
- Reduce Maintainability: Not using provided input validation frameworks can hurt the maintainability of code, since future developers may not recognize the downstream input validation that is required or expected in place of a validation framework.

## Cómo evitarlo

- Properly use provided input validation frameworks.
