# CWE-540: Inclusion of Sensitive Information in Source Code

**Tipo de fallo de software CWE-540** (Base).

The product (such as a web server or repository) provides access to source code is not intended to be accessible to users but contains sensitive information.

- **Es un caso de:** [CWE-538](/seguridad/cwe/CWE-538.md)

## Consecuencias

- Read Application Data: Obtaining source code on a system allows an attacker to understand the logic of the script and extract extremely useful information such as code bugs or logins and passwords.

## Cómo evitarlo

- Recommendations include removing the script from the web server and moving it to a location not accessible from the Internet.
