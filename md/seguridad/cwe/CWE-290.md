# CWE-290: Authentication Bypass by Spoofing

**Tipo de fallo de software CWE-290** (Base).

This attack-focused weakness is caused by incorrectly implemented authentication schemes that are subject to spoofing attacks.

- **Es un caso de:** [CWE-1390](/seguridad/cwe/CWE-1390.md), [CWE-287](/seguridad/cwe/CWE-287.md)

## Consecuencias

- Bypass Protection Mechanism: This weakness can allow an attacker to access resources which are not otherwise accessible without proper authentication.
