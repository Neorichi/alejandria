# S1046 PowGoop (Malware)

**Malware de MITRE ATT&CK** S1046.

- **Plataformas:** Windows

PowGoop is a loader that consists of a DLL loader and a PowerShell-based downloader; it has been used by MuddyWater as their main loader.
