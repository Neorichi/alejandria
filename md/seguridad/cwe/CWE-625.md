# CWE-625: Permissive Regular Expression

**Tipo de fallo de software CWE-625** (Base).

The product uses a regular expression that does not sufficiently restrict the set of allowed values.

- **Es un caso de:** [CWE-185](/seguridad/cwe/CWE-185.md)

## Consecuencias

- Bypass Protection Mechanism: The regexp could accept substrings that match the pattern, which produces a partial comparison to the target. In some cases, this can allow dangerous substrings to bypass the intended protection.

## Cómo evitarlo

- When applicable, ensure that the regular expression marks beginning and ending string patterns, such as "/^string$/" for Perl.
