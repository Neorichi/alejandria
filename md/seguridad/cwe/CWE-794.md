# CWE-794: Incomplete Filtering of Multiple Instances of Special Elements

**Tipo de fallo de software CWE-794** (Variant).

The product receives data from an upstream component, but it does not filter all instances of a special element before sending it to a downstream component.

Incomplete filtering of this nature may be applied to: sequential elements (special elements that appear next to each other) or non-sequential elements (special elements that appear multiple times in different locations).

- **Es un caso de:** [CWE-792](/seguridad/cwe/CWE-792.md)
