# CWE-1025: Comparison Using Wrong Factors

**Tipo de fallo de software CWE-1025** (Class).

The code performs a comparison between two entities, but the comparison examines the wrong factors or characteristics of the entities.

- **Es un caso de:** [CWE-697](/seguridad/cwe/CWE-697.md)

## Consecuencias

- Varies by Context: This can lead to incorrect results and resultant weaknesses. For example, the code might inadvertently compare references to objects, instead of the relevant contents of those objects, causing two "equal" objects to be considered unequal.
