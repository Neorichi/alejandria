# S1158 DUSTPAN (Malware)

**Malware de MITRE ATT&CK** S1158.

- **Plataformas:** Windows

DUSTPAN is an in-memory dropper written in C/C++ used by APT41 since 2021 that decrypts and executes an embedded payload.
