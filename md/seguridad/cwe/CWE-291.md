# CWE-291: Reliance on IP Address for Authentication

**Tipo de fallo de software CWE-291** (Variant).

The product uses an IP address for authentication.

- **Es un caso de:** [CWE-290](/seguridad/cwe/CWE-290.md), [CWE-923](/seguridad/cwe/CWE-923.md)

## Consecuencias

- Hide Activities: IP addresses can be easily spoofed. Malicious users can fake authentication information, impersonating any IP address. Attackers can forge the source IP address of the packets they send, but response packets will return to the forged IP address. To see the response packets, the attacker has to sniff the traffic between the victim machine and the forged IP address. In order to accomplish the required sniffing, attackers typically attempt to locate themselves on the same subnet as the victim machine, or to compromise an intermediary such as a router or proxy. Attackers may be able to circumvent this requirement by using source routing, but source routing is disabled across much of the Internet today.

## Cómo evitarlo

- Use other means of identity verification that cannot be simply spoofed. Possibilities include a username/password or certificate. While IP address verification can be a useful part of an authentication scheme, but it should not be the single factor required for authentication.
