# CWE-622: Improper Validation of Function Hook Arguments

**Tipo de fallo de software CWE-622** (Variant).

The product adds hooks to user-accessible API functions, but it does not properly validate the arguments.

- **Es un caso de:** [CWE-20](/seguridad/cwe/CWE-20.md)

## Consecuencias

- Unexpected State: When the arguments are not validated, they could be used to bypass the protection mechanism or attack the product itself. This could lead to resultant vulnerabilities.

## Cómo evitarlo

- Ensure that all arguments are verified, as defined by the API you are protecting.
- Drop privileges before invoking such functions, if possible.
