# CWE-244: Improper Clearing of Heap Memory Before Release

**Tipo de fallo de software CWE-244** (Variant).

The product uses realloc() to resize buffers that contain sensitive information.

- **Es un caso de:** [CWE-226](/seguridad/cwe/CWE-226.md)

## Consecuencias

- Read Memory: Since realloc() leaves the contents of the original block intact but inaccessible to the program, this the program from being able to scrub sensitive data from memory. When sensitive data such as a password or an encryption key is not removed from memory, an attacker could use "heap inspection" to read the sensitive data using memory dumps or other methods.
