# S9025 NOOPLDR (Malware)

**Malware de MITRE ATT&CK** S9025.

- **Plataformas:** Windows

NOOPLDR is a shellcode loader with XML/C# and DLL versions that has been used by MirrorFace to load HiddenFace.
