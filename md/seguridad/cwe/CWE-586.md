# CWE-586: Explicit Call to Finalize()

**Tipo de fallo de software CWE-586** (Base).

The product makes an explicit call to the finalize() method from outside the finalizer.

- **Es un caso de:** [CWE-1076](/seguridad/cwe/CWE-1076.md)

## Consecuencias

- Unexpected State: While the Java Language Specification allows an object's finalize() method to be called from outside the finalizer, doing so is usually a bad idea. For example, calling finalize() explicitly means that finalize() will be called more than once: the first time will be the explicit call and the last time will be the call that is made after the object is garbage collected.

## Cómo evitarlo

- Do not make explicit calls to finalize().
