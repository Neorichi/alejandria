# S0092 Agent.btz (Malware)

**Malware de MITRE ATT&CK** S0092.

- **Plataformas:** Windows

Agent.btz is a worm that primarily spreads itself via removable devices such as USB drives. It reportedly infected U.S. military networks in 2008.
