# CWE-524: Use of Cache Containing Sensitive Information

**Tipo de fallo de software CWE-524** (Base).

The code uses a cache that contains sensitive information, but the cache can be read by an actor outside of the intended control sphere.

- **Es un caso de:** [CWE-668](/seguridad/cwe/CWE-668.md)

## Consecuencias

- Read Application Data: If the cache is accessible to unauthorized actors, attackers can read the cache and obtain this sensitive information.

## Cómo evitarlo

- Protect information stored in cache.
- Do not store unnecessarily sensitive information in the cache.
- Consider using encryption in the cache.
