# S0460 Get2 (Malware)

**Malware de MITRE ATT&CK** S0460.

- **Plataformas:** Windows

Get2 is a downloader written in C++ that has been used by TA505 to deliver FlawedGrace, FlawedAmmyy, Snatch and SDBbot.
