# S0034 NETEAGLE (Malware)

**Malware de MITRE ATT&CK** S0034.

- **Plataformas:** Windows

NETEAGLE is a backdoor developed by APT30 with compile dates as early as 2008. It has two main variants known as “Scout” and “Norton.”
