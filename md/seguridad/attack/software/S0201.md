# S0201 JPIN (Malware)

**Malware de MITRE ATT&CK** S0201.

- **Plataformas:** Windows

JPIN is a custom-built backdoor family used by PLATINUM. Evidence suggests developers of JPIN and Dipsind code bases were related in some way.
