# S0644 ObliqueRAT (Malware)

**Malware de MITRE ATT&CK** S0644.

- **Plataformas:** Windows

ObliqueRAT is a remote access trojan, similar to Crimson, that has been in use by Transparent Tribe since at least 2020.
