# CWE-1469: Improper Check for Credential Expiration

**Tipo de fallo de software CWE-1469** (Base).

The product receives a request that includes a credential such as a key, certificate, password, confirmation code, or token, but the product does not check whether the credential is expired.

- **Es un caso de:** [CWE-284](/seguridad/cwe/CWE-284.md)

## Consecuencias

- Gain Privileges or Assume Identity: The consequences vary depending on how the credential is intended for use within the product. If an attacker steals or guesses the expired credential, then the attacker would have more time than desired in order to conduct malicious activities.

## Cómo evitarlo

- When receiving a credential, look up its expiration to ensure that the credential is still active. If the incoming credential states its own expiration, do not trust this value as it may be part of untrusted input.
- Ensure that, for any flow that generates or resets credentials, the expiration is clearly recorded for the credential. Also, ensure that mechanisms exist (such as error handling) for implementations to easily check for expiration, or build in the expiration check as part of the design.
