# CWE-843: Access of Resource Using Incompatible Type

**Tipo de fallo de software CWE-843** (Base).

The product allocates or initializes a resource such as a pointer, object, or variable using one type, but it later accesses that resource using a type that is incompatible with the original type.

- **Es un caso de:** [CWE-704](/seguridad/cwe/CWE-704.md)

## Consecuencias

- Varies by Context: When the product accesses the resource using an incompatible type, this could trigger logical errors because the resource does not have expected properties.
- Read Memory: If a memory buffer is accessed using an incompatible type, and the allocated buffer is smaller than the type that the code is attempting to access, then an attacker could read or write memory outside the bounds of the buffer, leading to a crash or possibly code execution.
