# CWE-1043: Data Element Aggregating an Excessively Large Number of Non-Primitive Elements

**Tipo de fallo de software CWE-1043** (Base).

The product uses a data element that has an excessively large number of sub-elements with non-primitive data types such as structures or aggregated objects.

- **Es un caso de:** [CWE-1093](/seguridad/cwe/CWE-1093.md)

## Consecuencias

- Reduce Performance: This issue can make the product perform more slowly. If the relevant code is reachable by an attacker, then this performance problem might introduce a vulnerability.
