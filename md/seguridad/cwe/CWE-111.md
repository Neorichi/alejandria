# CWE-111: Direct Use of Unsafe JNI

**Tipo de fallo de software CWE-111** (Variant).

When a Java application uses the Java Native Interface (JNI) to call code written in another programming language, it can expose the application to weaknesses in that code, even if those weaknesses cannot occur in Java.

- **Es un caso de:** [CWE-695](/seguridad/cwe/CWE-695.md), [CWE-20](/seguridad/cwe/CWE-20.md)

## Consecuencias

- Bypass Protection Mechanism

## Cómo evitarlo

- Implement error handling around the JNI call.
- Do not use JNI calls if the native library can't be trusted.
- Be reluctant to use JNI calls. A Java API equivalent may exist.
