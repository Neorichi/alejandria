# CWE-1318: Missing Support for Security Features in On-chip Fabrics or Buses

**Tipo de fallo de software CWE-1318** (Base).

On-chip fabrics or buses either do not support or are not configured to support privilege separation or other security features, such as access control.

- **Es un caso de:** [CWE-693](/seguridad/cwe/CWE-693.md)

## Consecuencias

- DoS: Crash, Exit, or Restart

## Cómo evitarlo

- Such fabrics or buses should not be used to transport any security attribute coming from the bus master. In general, peripherals with security assets should not be connected to such buses before the transaction from the bus master reaches the bus, unless some form of access control is performed at a fabric bridge or another intermediate module. If the fabric does not support security features, implement security checks in a bridge or any component that is between the master and the fabric. Alternatively, connect all fabric slaves that do not have any security assets under one such fabric and connect peripherals with security assets to a different fabric that supports security features.
