# CWE-456: Missing Initialization of a Variable

**Tipo de fallo de software CWE-456** (Variant).

The product does not initialize critical variables.

- **Es un caso de:** [CWE-909](/seguridad/cwe/CWE-909.md), [CWE-665](/seguridad/cwe/CWE-665.md)

## Consecuencias

- Unexpected State: The execution environment might use unexpected values. The uninitialized data may be invalid, causing logic errors within the program. In some cases, this could result in a security problem.

## Cómo evitarlo

- Ensure that critical variables are initialized before first use [REF-1485].
- Choose a language that is not susceptible to these issues.
