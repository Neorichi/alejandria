# Cangrelor

**Cangrelor**, es vendido bajo la marca Kengreal entre otras, es un medicamento utilizado en pacientes sometidos a intervención coronaria percutánea  para prevenir coágulos sanguíneos. Se utiliza con aspirina. Este medicamento se administra mediante inyección en una vena.

Los efectos secundarios de este medicamento incluyen sangrado y dificultad para respirar;  otros efectos secundarios pueden incluir reacciones alérgicas. La seguridad de este medicamento durante el embarazo no está clara. Es un inhibidor del P2Y 12 que impide que las plaquetas se adhieran entre sí.

Este medicamento fue aprobado para uso médico en los Estados Unidos y Europa en 2015. En el Reino Unido, 50 mg le costaron al NHS aproximadamente 250 libras esterlinas en 2021. Esta cantidad en Estados Unidos cuesta unos 830 USD.
