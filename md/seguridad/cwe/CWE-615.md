# CWE-615: Inclusion of Sensitive Information in Source Code Comments

**Tipo de fallo de software CWE-615** (Variant).

The product's source code includes comments that contain sensitive information, such as filenames related to the application, old links or links that were not meant to be browsed by users, old code fragments, etc.

- **Es un caso de:** [CWE-540](/seguridad/cwe/CWE-540.md)

## Consecuencias

- Read Application Data: An attacker who finds these comments can map the application's structure and files, expose hidden parts of the site, and study the fragments of code to reverse engineer the application, which may help develop further attacks against the site.

## Cómo evitarlo

- Remove comments which have sensitive information about the design/implementation of the application. Some of the comments may be exposed to the user and affect the security posture of the application.
