# CWE-514: Covert Channel

**Tipo de fallo de software CWE-514** (Class).

A covert channel is a path that can be used to transfer information in a way not intended by the system's designers.

- **Es un caso de:** [CWE-1229](/seguridad/cwe/CWE-1229.md)

## Consecuencias

- Hide Activities: Typically the system has not given authorization for the transmission and has no knowledge of its occurrence.
