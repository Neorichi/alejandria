# S1227 StarProxy (Malware)

**Malware de MITRE ATT&CK** S1227.

- **Plataformas:** Windows

StarProxy is custom malware used by Mustang Panda as a post-compromise tool, to enable proxying of traffic between the infected machine and other machines on the same network.
