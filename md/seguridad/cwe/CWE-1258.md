# CWE-1258: Exposure of Sensitive System Information Due to Uncleared Debug Information

**Tipo de fallo de software CWE-1258** (Base).

The hardware product enters debug mode but does not fully clear security-sensitive values, such as keys and intermediate values in cryptographic operations.

Security sensitive values, keys, intermediate steps of cryptographic operations, etc. are stored in temporary registers in the hardware.

- **Es un caso de:** [CWE-1272](/seguridad/cwe/CWE-1272.md)

## Consecuencias

- Read Memory: Sensitive data could be accessed by a debugger, allowing sensitive information to be accessible by untrusted parties.
- Bypass Protection Mechanism

## Cómo evitarlo

- Whenever debug mode is enabled, all registers containing sensitive assets must be cleared.
