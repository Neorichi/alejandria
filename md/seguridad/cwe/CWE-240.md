# CWE-240: Improper Handling of Inconsistent Structural Elements

**Tipo de fallo de software CWE-240** (Class).

The product does not handle or incorrectly handles when two or more structural elements should be consistent, but are not.

- **Es un caso de:** [CWE-237](/seguridad/cwe/CWE-237.md), [CWE-707](/seguridad/cwe/CWE-707.md)

## Consecuencias

- Varies by Context: If multiple structural elements are inconsistent, then using these elements could place the system into an unexpected state that could lead to a crash, consume available resources, or other unintended behaviors.
