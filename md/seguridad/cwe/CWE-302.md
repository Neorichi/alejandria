# CWE-302: Authentication Bypass by Assumed-Immutable Data

**Tipo de fallo de software CWE-302** (Base).

The authentication scheme or implementation uses key data elements that are assumed to be immutable, but can be controlled or modified by the attacker.

- **Es un caso de:** [CWE-1390](/seguridad/cwe/CWE-1390.md), [CWE-807](/seguridad/cwe/CWE-807.md)

## Consecuencias

- Bypass Protection Mechanism

## Cómo evitarlo

- Implement proper protection for immutable data (e.g. environment variable, hidden form fields, etc.)
