# S0446 Ryuk (Malware)

**Malware de MITRE ATT&CK** S0446.

- **Plataformas:** Windows

Ryuk is a ransomware designed to target enterprise environments that has been used in attacks since at least 2018. Ryuk shares code similarities with Hermes ransomware.
