# CWE-561: Dead Code

**Tipo de fallo de software CWE-561** (Base).

The product contains dead code, which can never be executed.

- **Es un caso de:** [CWE-1164](/seguridad/cwe/CWE-1164.md)

## Consecuencias

- Quality Degradation: Dead code that results from code that can never be executed is an indication of problems with the source code that needs to be fixed and is an indication of poor quality.
- Reduce Maintainability
- Varies by Context: In some cases, dead code can be reachable or exploitable by attackers after they exploit another weakness or vulnerability that can access the code. For example, some buffer overflow exploits could modify addresses to point to locations that contain dead code.

## Cómo evitarlo

- Remove dead code before deploying the application.
