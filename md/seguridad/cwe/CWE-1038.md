# CWE-1038: Insecure Automated Optimizations

**Tipo de fallo de software CWE-1038** (Class).

The product uses a mechanism that automatically optimizes code, e.g. to improve a characteristic such as performance, but the optimizations can have an unintended side effect that might violate an intended security assumption.

- **Es un caso de:** [CWE-435](/seguridad/cwe/CWE-435.md), [CWE-758](/seguridad/cwe/CWE-758.md)

## Consecuencias

- Alter Execution Logic: The optimizations alter the order of execution resulting in side effects that were not intended by the original developer.
