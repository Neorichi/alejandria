# CWE-1051: Initialization with Hard-Coded Network Resource Configuration Data

**Tipo de fallo de software CWE-1051** (Base).

The product initializes data using hard-coded values that act as network resource identifiers.

- **Es un caso de:** [CWE-1419](/seguridad/cwe/CWE-1419.md)

## Consecuencias

- Reduce Reliability: This issue can prevent the product from running reliably, e.g. if it runs in an environment does not use the hard-coded network resource identifiers. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
