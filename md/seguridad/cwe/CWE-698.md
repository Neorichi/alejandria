# CWE-698: Execution After Redirect (EAR)

**Tipo de fallo de software CWE-698** (Base).

The web application sends a redirect to another location, but instead of exiting, it executes additional code.

- **Es un caso de:** [CWE-705](/seguridad/cwe/CWE-705.md), [CWE-670](/seguridad/cwe/CWE-670.md)

## Consecuencias

- Alter Execution Logic: This weakness could affect the control flow of the application and allow execution of untrusted code.
