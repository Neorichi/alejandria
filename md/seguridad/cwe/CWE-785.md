# CWE-785: Use of Path Manipulation Function without Maximum-sized Buffer

**Tipo de fallo de software CWE-785** (Variant).

The product invokes a function for normalizing paths or file names, but it provides an output buffer that is smaller than the maximum possible size, such as PATH_MAX.

Path manipulation functions include realpath(), readlink(), PathAppend(), and others.

- **Es un caso de:** [CWE-676](/seguridad/cwe/CWE-676.md), [CWE-787](/seguridad/cwe/CWE-787.md), [CWE-20](/seguridad/cwe/CWE-20.md)

## Consecuencias

- Modify Memory: Passing an inadequately-sized output buffer to a path manipulation function can result in a buffer overflow.

## Cómo evitarlo

- Always specify output buffers large enough to handle the maximum-size possible result from path manipulation functions.
