# CWE-393: Return of Wrong Status Code

**Tipo de fallo de software CWE-393** (Base).

A function or operation returns an incorrect return value or status code that does not indicate the true result of execution, causing the product to modify its behavior based on the incorrect result.

- **Es un caso de:** [CWE-684](/seguridad/cwe/CWE-684.md), [CWE-703](/seguridad/cwe/CWE-703.md)

## Consecuencias

- Unexpected State: This weakness can lead to unpredictable behavior. If the function is used to make security-critical decisions or provide security-critical information, then the wrong status code can cause the product to assume that an action is safe or correct, even when it is not. This weakness could place the system in a state that could lead unexpected logic to be executed or other unintended behaviors.
