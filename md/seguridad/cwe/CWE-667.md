# CWE-667: Improper Locking

**Tipo de fallo de software CWE-667** (Class).

The product does not properly acquire or release a lock on a resource, leading to unexpected resource state changes and behaviors.

- **Es un caso de:** [CWE-662](/seguridad/cwe/CWE-662.md)

## Consecuencias

- DoS: Resource Consumption (CPU): Inconsistent locking discipline can lead to deadlock.
- Modify Memory: This can lead to data or memory corruption.
- Varies by Context: This can lead to unexpected resource state changes and behaviors.

## Cómo evitarlo

- Use industry standard APIs to implement locking mechanism.
