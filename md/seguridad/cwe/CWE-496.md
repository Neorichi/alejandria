# CWE-496: Public Data Assigned to Private Array-Typed Field

**Tipo de fallo de software CWE-496** (Variant).

Assigning public data to a private array is equivalent to giving public access to the array.

- **Es un caso de:** [CWE-668](/seguridad/cwe/CWE-668.md)

## Consecuencias

- Modify Application Data: The contents of the array can be modified from outside the intended scope.

## Cómo evitarlo

- Do not allow objects to modify private members of a class.
