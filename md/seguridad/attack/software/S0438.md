# S0438 Attor (Malware)

**Malware de MITRE ATT&CK** S0438.

- **Plataformas:** Windows

Attor is a Windows-based espionage platform that has been seen in use since 2013. Attor has a loadable plugin architecture to customize functionality for specific targets.
