# CWE-1037: Processor Optimization Removal or Modification of Security-critical Code

**Tipo de fallo de software CWE-1037** (Base).

The developer builds a security-critical protection mechanism into the software, but the processor optimizes the execution of the program such that the mechanism is removed or modified.

- **Es un caso de:** [CWE-1038](/seguridad/cwe/CWE-1038.md)

## Consecuencias

- Bypass Protection Mechanism: A successful exploitation of this weakness will change the order of an application's execution and will likely be used to bypass specific protection mechanisms. This bypass can be exploited further to potentially read data that should otherwise be unaccessible.
