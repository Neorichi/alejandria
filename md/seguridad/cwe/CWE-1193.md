# CWE-1193: Power-On of Untrusted Execution Core Before Enabling Fabric Access Control

**Tipo de fallo de software CWE-1193** (Base).

The product enables components that contain untrusted firmware before memory and fabric access controls have been enabled.

- **Es un caso de:** [CWE-696](/seguridad/cwe/CWE-696.md)

## Consecuencias

- Bypass Protection Mechanism: If untrusted IPs or peripheral microcontrollers are enabled too soon, then the untrusted component can master transactions on the hardware bus and target memory or other assets to compromise the SoC boot firmware.

## Cómo evitarlo

- The boot sequence should enable fabric access controls and memory protections before enabling third-party hardware IPs and peripheral microcontrollers that use untrusted firmware.
