# CWE-1094: Excessive Index Range Scan for a Data Resource

**Tipo de fallo de software CWE-1094** (Base).

The product contains an index range scan for a large data table, but the scan can cover a large number of rows.

- **Es un caso de:** [CWE-405](/seguridad/cwe/CWE-405.md)

## Consecuencias

- Reduce Performance: This issue can make the product perform more slowly. If the relevant code is reachable by an attacker, then this performance problem might introduce a vulnerability.
