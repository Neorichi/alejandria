# S0394 HiddenWasp (Malware)

**Malware de MITRE ATT&CK** S0394.

- **Plataformas:** Linux

HiddenWasp is a Linux-based Trojan used to target systems for remote control. It comes in the form of a statically linked ELF binary with stdlibc++.
