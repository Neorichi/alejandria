# Dinutuximab

- **Drug name:** Dinutuximab
- **Type:** mab
- **Mab type:** mab
- **Source:** xi/o
- **Target:** GD2
- **Tradename:** Unituxin, Isquette, Qarziba, others
- **Synonyms:** Dinutuximab beta, Ch14.18, APN-311
- **Medlineplus:** a615022
- **Embarazo au:** C
- **Embarazo us:** N

El **dinutuximab**, es comercializado bajo el nombre **Qarziba**, entre otros, es un medicamento utilizado para tratar el neuroblastoma. Se utiliza para niños de alto riesgo que todavía tienen problemas a pesar de otros tratamientos. Este medicamento se administra mediante inyección en una vena.

Los efectos secundarios de este medicamento  incluyen dolor, fiebre, reacción a la infusión, niveles bajos de plaquetas, niveles bajos de glóbulos blancos, niveles bajos de potasio, síndrome de fuga capilar y problemas hepáticos. Otros efectos secundarios pueden incluir síndrome de leucoencefalopatía posterior reversible, mielitis transversa, problemas oculares e infección. El uso de este medicamento                                                                                                     durante el embarazo puede dañar al bebé. Es un anticuerpo monoclonal que se une a GD2, comúnmente encontrado en las células del neuroblastoma. Esta unión hace que el sistema inmunológico del cuerpo los destruya.

Este medicamento fue aprobado para uso médico en los Estados Unidos en 2015. Si bien también fue aprobado en Europa en 2015, posteriormente fue retirado en 2017. Dinutuximab beta; sin embargo, recibió aprobación en Europa en 2017. En Estados Unidos, 17,5 mg costaba alrededor de 14.000 dólares estadounidenses  en 2021.
