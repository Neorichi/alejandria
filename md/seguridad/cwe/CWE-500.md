# CWE-500: Public Static Field Not Marked Final

**Tipo de fallo de software CWE-500** (Variant).

An object contains a public static field that is not marked final.

- **Es un caso de:** [CWE-493](/seguridad/cwe/CWE-493.md)

## Consecuencias

- Modify Application Data: The object could potentially be tampered with in unexpected ways. Public static variables can be read without an accessor and changed without a mutator by any classes in the application.
- Read Application Data: The object could potentially allow the object to be read.

## Cómo evitarlo

- Clearly identify the scope for all critical data elements, including whether they should be regarded as static.
- Make any static fields private and constant. A constant field is denoted by the keyword 'const' in C/C++ and ' final' in Java
