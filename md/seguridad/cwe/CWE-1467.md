# CWE-1467: Use of Singular Authentication Artifact for Multiple User Sessions

**Tipo de fallo de software CWE-1467** (Base).

The product provides an authentication artifact, such as an authentication token, for an authenticated user session, but the same artifact is used for every authenticated user session, potentially across multiple different applications.

- **Es un caso de:** [CWE-1462](/seguridad/cwe/CWE-1462.md)

## Consecuencias

- Gain Privileges or Assume Identity: If an authentication artifact is used across multiple applications or services, it allows an adversary who is able to compromise the authentication artifact to gain access to all applications or services that use that artifact.
- Other: In order to revoke access to an adversary who has compromised a shared authentication artifact, that artifact must be invalidated which would affect the availability of any user who has legitimately obtained the artifact to authenticate.

## Cómo evitarlo

- Enforce re-authentication per user device. This prevents another user from obtaining the singular authentication artifact and making authenticated requests without authenticating.
- Use unique authentication artifacts per user device that will only be accepted if used on that device.
- Ensure that unique authentication artifacts are used for each application or service within an organization to prevent potential reuse across applications.
