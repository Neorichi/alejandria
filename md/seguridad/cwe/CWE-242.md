# CWE-242: Use of Inherently Dangerous Function

**Tipo de fallo de software CWE-242** (Base).

The product calls a function that can never be guaranteed to work safely, regardless of how it is used.

- **Es un caso de:** [CWE-1177](/seguridad/cwe/CWE-1177.md)

## Consecuencias

- Varies by Context: The consequences vary depending on the behavior of the affected function.
- Modify Memory: Some functions can be subject to buffer overflows. For example, an attacker can easily send arbitrarily-sized input to gets() and overflow the destination buffer. In C++, an attacker can easily send arbitrarily-sized input to the >> operator and overflow the destination buffer.

## Cómo evitarlo

- Identify a list of prohibited API functions and prohibit developers from using these functions, providing safer alternatives. In some cases, automatic code analysis tools or the compiler can be instructed to spot use of prohibited functions, such as the "banned.h" include file from Microsoft's SDL. [REF-554] [REF-1009] [REF-7]
- Use grep or static analysis tools to spot usage of dangerous functions.
