# S0275 UPPERCUT (Malware)

**Malware de MITRE ATT&CK** S0275.

- **Plataformas:** Windows

UPPERCUT is a 32-bit HTTP-based backdoor that has been used by menuPass since at least 2017. Once thought to be exclusive to menuPass, UPPERCUT was also observed being used by menuPass-associated MirrorFace during Operation AkaiRyū.
