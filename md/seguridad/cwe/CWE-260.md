# CWE-260: Password in Configuration File

**Tipo de fallo de software CWE-260** (Base).

The product stores a password in a configuration file that might be accessible to actors who do not know the password.

- **Es un caso de:** [CWE-522](/seguridad/cwe/CWE-522.md)

## Consecuencias

- Gain Privileges or Assume Identity: This can result in compromise of the system for which the password is used. An attacker could gain access to this file and learn the stored password or worse yet, change the password to one of their choosing.

## Cómo evitarlo

- Avoid storing passwords in easily accessible locations.
- Consider storing cryptographic hashes of passwords as an alternative to storing in plaintext.
