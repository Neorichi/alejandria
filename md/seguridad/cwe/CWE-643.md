# CWE-643: Improper Neutralization of Data within XPath Expressions

**Tipo de fallo de software CWE-643** (Base).

The product uses external input to dynamically construct an XPath expression used to retrieve data from an XML database, but it does not neutralize or incorrectly neutralizes that input.

- **Es un caso de:** [CWE-943](/seguridad/cwe/CWE-943.md), [CWE-91](/seguridad/cwe/CWE-91.md)

## Consecuencias

- Bypass Protection Mechanism: An attacker can control the structure of the query, possibly causing unexpected data to be returned. This can be further used to control application flow (e.g., bypassing authentication).
- Read Application Data: By modifying the XPath query, an attacker could read restricted XML content by choosing which information is selected from the XML database.

## Cómo evitarlo

- Use parameterized XPath queries (e.g. using XQuery). This will help ensure separation between data plane and control plane.
- Properly validate user input. Reject data where appropriate, filter where appropriate and escape where appropriate. Make sure input that will be used in XPath queries is safe in that context.
