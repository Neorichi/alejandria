# CWE-1046: Creation of Immutable Text Using String Concatenation

**Tipo de fallo de software CWE-1046** (Base).

The product creates an immutable text string using string concatenation operations.

- **Es un caso de:** [CWE-1176](/seguridad/cwe/CWE-1176.md)

## Consecuencias

- Reduce Performance: When building a string via a looping feature (e.g., a FOR or WHILE loop), the use of += to append to the existing string will result in the creation of a new object with each iteration, which can be inefficient in comparison with use of text buffer data elements. This issue can make the product perform more slowly. If the relevant code is reachable by an attacker, then this could be influenced to create performance problems.
