# CWE-383: J2EE Bad Practices: Direct Use of Threads

**Tipo de fallo de software CWE-383** (Variant).

Thread management in a Web application is forbidden in some circumstances and is always highly error prone.

- **Es un caso de:** [CWE-695](/seguridad/cwe/CWE-695.md)

## Consecuencias

- Quality Degradation: Even without interfering with the container, thread management usually leads to bugs that are hard to detect and diagnose, such as deadlock, race conditions, and other synchronization errors.

## Cómo evitarlo

- For EJB, use framework approaches for parallel execution, instead of using threads.
