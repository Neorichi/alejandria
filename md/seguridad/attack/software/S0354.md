# S0354 Denis (Malware)

**Malware de MITRE ATT&CK** S0354.

- **Plataformas:** Windows

Denis is a Windows backdoor and Trojan used by APT32. Denis shares several similarities to the SOUNDBITE backdoor and has been used in conjunction with the Goopy backdoor.
