# CWE-593: Authentication Bypass: OpenSSL CTX Object Modified after SSL Objects are Created

**Tipo de fallo de software CWE-593** (Variant).

The product modifies the SSL context after connection creation has begun.

- **Es un caso de:** [CWE-666](/seguridad/cwe/CWE-666.md), [CWE-1390](/seguridad/cwe/CWE-1390.md)

## Consecuencias

- Bypass Protection Mechanism: No authentication takes place in this process, bypassing an assumed protection of encryption.
- Read Application Data: If the program modifies the SSL_CTX object after creating SSL objects from it, there is the possibility that older SSL objects created from the original context could all be affected by that change. The encrypted communication between a user and a trusted host may be subject to a sniffing attack.

## Cómo evitarlo

- Use a language or a library that provides a cryptography framework at a higher level of abstraction.
- Most SSL_CTX functions have SSL counterparts that act on SSL-type objects.
- Applications should set up an SSL_CTX completely, before creating SSL objects from it.
