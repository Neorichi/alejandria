# CWE-1058: Invokable Control Element in Multi-Thread Context with non-Final Static Storable or Member Element

**Tipo de fallo de software CWE-1058** (Base).

The code contains a function or method that operates in a multi-threaded environment but owns an unsafe non-final static storable or member data element.

- **Es un caso de:** [CWE-662](/seguridad/cwe/CWE-662.md)

## Consecuencias

- Reduce Reliability: This issue can prevent the product from running reliably. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
