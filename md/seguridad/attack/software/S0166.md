# S0166 RemoteCMD (Malware)

**Malware de MITRE ATT&CK** S0166.

- **Plataformas:** Windows

RemoteCMD is a custom tool used by APT3 to execute commands on a remote system similar to SysInternal's PSEXEC functionality.
