# CWE-555: J2EE Misconfiguration: Plaintext Password in Configuration File

**Tipo de fallo de software CWE-555** (Variant).

The J2EE application stores a plaintext password in a configuration file.

- **Es un caso de:** [CWE-260](/seguridad/cwe/CWE-260.md)

## Consecuencias

- Bypass Protection Mechanism: Storing a plaintext password in a configuration file allows anyone who can read the file to access the password-protected resource, making it an easy target for attackers.

## Cómo evitarlo

- Do not hardwire passwords into your software.
- Use industry standard libraries to encrypt passwords before storage in configuration files.
