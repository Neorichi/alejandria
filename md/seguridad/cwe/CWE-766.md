# CWE-766: Critical Data Element Declared Public

**Tipo de fallo de software CWE-766** (Base).

The product declares a critical variable, field, or member to be public when intended security policy requires it to be private.

- **Es un caso de:** [CWE-732](/seguridad/cwe/CWE-732.md), [CWE-1061](/seguridad/cwe/CWE-1061.md)

## Consecuencias

- Read Application Data: Making a critical variable public allows anyone with access to the object in which the variable is contained to alter or read the value.
- Reduce Maintainability: This issue makes it more difficult to maintain the product, which indirectly affects security by making it more difficult or time-consuming to find and/or fix vulnerabilities.

## Cómo evitarlo

- Data should be private, static, and final whenever possible. This will assure that your code is protected by instantiating early, preventing access, and preventing tampering.
