# CWE-530: Exposure of Backup File to an Unauthorized Control Sphere

**Tipo de fallo de software CWE-530** (Variant).

A backup file is stored in a directory or archive that is made accessible to unauthorized actors.

- **Es un caso de:** [CWE-552](/seguridad/cwe/CWE-552.md)

## Consecuencias

- Read Application Data: At a minimum, an attacker who retrieves this file would have all the information contained in it, whether that be database calls, the format of parameters accepted by the application, or simply information regarding the architectural structure of your site. The source code for old files that were renamed in this manner and left in the webroot can often be retrieved.

## Cómo evitarlo

- Recommendations include implementing a security policy within your organization that prohibits backing up web application source code in the webroot.
