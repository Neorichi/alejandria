# CWE-349: Acceptance of Extraneous Untrusted Data With Trusted Data

**Tipo de fallo de software CWE-349** (Base).

The product, when processing trusted data, accepts any untrusted data that is also included with the trusted data, treating the untrusted data as if it were trusted.

- **Es un caso de:** [CWE-345](/seguridad/cwe/CWE-345.md)

## Consecuencias

- Bypass Protection Mechanism: An attacker could package untrusted data with trusted data to bypass protection mechanisms to gain access to and possibly modify sensitive data.
