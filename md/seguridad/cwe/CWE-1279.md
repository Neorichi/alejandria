# CWE-1279: Cryptographic Operations are Run Before Supporting Units are Ready

**Tipo de fallo de software CWE-1279** (Base).

Performing cryptographic operations without ensuring that the supporting inputs are ready to supply valid data may compromise the cryptographic result.

- **Es un caso de:** [CWE-696](/seguridad/cwe/CWE-696.md), [CWE-665](/seguridad/cwe/CWE-665.md)

## Consecuencias

- Varies by Context

## Cómo evitarlo

- Best practices should be used to design cryptographic systems. If a cryptographic unit retrieves a private encryption key from a fuse unit, the fuse unit must be up and running before a key may be supplied.
- Continuously ensuring that cryptographic inputs are supplying valid information is necessary to ensure that the encrypted output is secure.
