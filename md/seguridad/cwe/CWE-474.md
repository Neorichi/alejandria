# CWE-474: Use of Function with Inconsistent Implementations

**Tipo de fallo de software CWE-474** (Base).

The code uses a function that has inconsistent implementations across operating systems and versions.

The implementation of many functions varies by platform, and at times, even by different versions of the same platform. Implementation differences can include: Slight differences in the way parameters are interpreted, leading to inconsistent results. Some implementations of the function carry significant security risks. The function might not be defined on all platforms. The function might change which return codes it can provide, or change the meaning of its return codes.

- **Es un caso de:** [CWE-758](/seguridad/cwe/CWE-758.md)

## Consecuencias

- Quality Degradation: The use of inconsistent implementations can cause changes in behavior when the code is ported or built under a different environment than the programmer expects, which can lead to security problems in some cases.

## Cómo evitarlo

- Do not accept inconsistent behavior from the API specifications when the deviant behavior increases the risk level.
