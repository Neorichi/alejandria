# CWE-588: Attempt to Access Child of a Non-structure Pointer

**Tipo de fallo de software CWE-588** (Variant).

The product casts a non-structure type to a structure type, then accesses a field within the structure.

- **Es un caso de:** [CWE-704](/seguridad/cwe/CWE-704.md), [CWE-758](/seguridad/cwe/CWE-758.md)

## Consecuencias

- Modify Memory: Adjacent variables in memory may be corrupted by assignments performed on fields after the cast, leading to data corruption.
- DoS: Crash, Exit, or Restart: Execution may end due to a memory access error.

## Cómo evitarlo

- The choice could be made to use a language that is not susceptible to these issues.
- Review of type casting operations can identify locations where incompatible types are cast.
