# CWE-1267: Policy Uses Obsolete Encoding

**Tipo de fallo de software CWE-1267** (Base).

The product uses an encoding mechanism that is no longer trusted, i.e., an obsolete encoding, to implement access controls.

- **Es un caso de:** [CWE-284](/seguridad/cwe/CWE-284.md)

## Consecuencias

- Modify Memory

## Cómo evitarlo

- Security Token Decoders should be reviewed for design inconsistency and common weaknesses. Access and programming flows should be tested in both pre-silicon and post-silicon testing.
