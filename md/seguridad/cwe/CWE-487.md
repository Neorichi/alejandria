# CWE-487: Reliance on Package-level Scope

**Tipo de fallo de software CWE-487** (Base).

Java packages are not inherently closed; therefore, relying on them for code security is not a good practice.

- **Es un caso de:** [CWE-664](/seguridad/cwe/CWE-664.md)

## Consecuencias

- Read Application Data: Any data in a Java package can be accessed outside of the Java framework if the package is distributed.
- Modify Application Data: The data in a Java class can be modified by anyone outside of the Java framework if the package is distributed.

## Cómo evitarlo

- Data should be private static and final whenever possible. This will assure that your code is protected by instantiating early, preventing access and tampering.
