# CWE-1282: Assumed-Immutable Data is Stored in Writable Memory

**Tipo de fallo de software CWE-1282** (Base).

Immutable data, such as a first-stage bootloader, device identifiers, and "write-once" configuration settings are stored in writable memory that can be re-programmed or updated in the field.

- **Es un caso de:** [CWE-668](/seguridad/cwe/CWE-668.md)

## Consecuencias

- Varies by Context: Security is lost if assets assumed to be immutable can be modified.

## Cómo evitarlo

- Storing immutable code or data in read-only memory (ROM), fuses, or one-time programmable (OTP) memory provides strong integrity guarantees and provides a root of trust for securing the rest of the system.
