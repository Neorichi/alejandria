# CWE-1290: Incorrect Decoding of Security Identifiers

**Tipo de fallo de software CWE-1290** (Base).

The product implements a decoding mechanism to decode certain bus-transaction signals to security identifiers, but it decodes an untrusted agent's security identifier into a trusted agent's security identifier.

- **Es un caso de:** [CWE-1294](/seguridad/cwe/CWE-1294.md)

## Consecuencias

- Modify Memory: If the decoding of an untrusted agent's identifier produces the security identifier of a trusted agent, then the untrusted agent can gain unauthorized access to the asset.

## Cómo evitarlo

- Security identifier decoders must be reviewed for design consistency and common weaknesses.
- Access and programming flows must be tested in pre-silicon and post-silicon testing in order to check for this weakness.
