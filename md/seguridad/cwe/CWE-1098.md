# CWE-1098: Data Element containing Pointer Item without Proper Copy Control Element

**Tipo de fallo de software CWE-1098** (Base).

The code contains a data element with a pointer that does not have an associated copy or constructor method.

- **Es un caso de:** [CWE-1076](/seguridad/cwe/CWE-1076.md)

## Consecuencias

- Reduce Reliability: This issue can prevent the product from running reliably. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
