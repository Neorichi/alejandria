# S0537 HyperStack (Malware)

**Malware de MITRE ATT&CK** S0537.

- **Plataformas:** Windows

HyperStack is a RPC-based backdoor used by Turla since at least 2018. HyperStack has similarities to other backdoors used by Turla including Carbon.
