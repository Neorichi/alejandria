# S1108 PULSECHECK (Malware)

**Malware de MITRE ATT&CK** S1108.

- **Plataformas:** Network Devices, Linux

PULSECHECK is a web shell written in Perl that was used by APT5 as early as 2020 including against Pulse Secure VPNs at US Defense Industrial Base (DIB) companies.
