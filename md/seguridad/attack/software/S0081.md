# S0081 Elise (Malware)

**Malware de MITRE ATT&CK** S0081.

- **Plataformas:** Windows

Elise is a custom backdoor Trojan that appears to be used exclusively by Lotus Blossom. It is part of a larger group of tools referred to as LStudio, ST Group, and APT0LSTU.
