# S0146 TEXTMATE (Malware)

**Malware de MITRE ATT&CK** S0146.

- **Plataformas:** Windows

TEXTMATE is a second-stage PowerShell backdoor that is memory-resident. It was observed being used along with POWERSOURCE in February 2017.
