# CWE-911: Improper Update of Reference Count

**Tipo de fallo de software CWE-911** (Base).

The product uses a reference count to manage a resource, but it does not update or incorrectly updates the reference count.

- **Es un caso de:** [CWE-664](/seguridad/cwe/CWE-664.md)

## Consecuencias

- DoS: Resource Consumption (Memory): If an adversary can prevent a reference count from reaching zero, then resources might not be released when they are supposed to, thus causing resources to become scarce for future needs.
- DoS: Crash, Exit, or Restart: If an adversary can cause a reference count to reach zero when the resource is still in use, then a resource might be released before it is supposed to be, possibly forcing an error that causes the product to crash or exit out of its current operation.
