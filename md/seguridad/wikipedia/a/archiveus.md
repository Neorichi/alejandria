# Archiveus

- **Género:** Troyano (informática)
- **Sistema operativo:** Microsoft Windows
- **Idiomas:** Inglés

**Archiveus** es un virus informático para sistemas operativos Microsoft Windows que se utiliza como método de extorsión.

Es un virus ransomware tipo troyano que cifra los archivos del usuario. El usuario debe entonces comprar algo en sitios web específicos para obtener la contraseña que le permita descifrar los archivos. El virus cifra principalmente los archivos ubicados en el directorio «Mis documentos» y exige a las víctimas que obtengan una contraseña de 30 dígitos para recuperar el acceso a sus datos.

En mayo de 2006, se descifró la protección por contraseña. Se descubrió que la contraseña para restaurar los archivos afectados era «mf2lro8sw03ufvnsq034jfowr18f3cszc20vmw». Aunque Archiveus ya no es una amenaza frecuente, desempeñó un papel importante en la evolución del ransomware.
