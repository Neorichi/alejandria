# CWE-539: Use of Persistent Cookies Containing Sensitive Information

**Tipo de fallo de software CWE-539** (Variant).

The web application uses persistent cookies, but the cookies contain sensitive information.

- **Es un caso de:** [CWE-552](/seguridad/cwe/CWE-552.md)

## Consecuencias

- Read Application Data: This can cause privacy issues depending on the information stored in the cookie and how it is accessed.
- Bypass Protection Mechanism: If the cookie is used for a protection mechanism (e.g., credentials), then an attacker might be able to bypass the mechanism using information from the cookie.

## Cómo evitarlo

- Do not store sensitive information in persistent cookies.
