# CWE-563: Assignment to Variable without Use

**Tipo de fallo de software CWE-563** (Base).

The variable's value is assigned but never used, i.e., is a dead store. That is, after the assignment, the variable is either assigned another value or goes out of scope.

- **Es un caso de:** [CWE-1164](/seguridad/cwe/CWE-1164.md)

## Consecuencias

- Quality Degradation: This weakness could be an indication of a bug in the program or a deprecated variable that was not removed and is an indication of poor quality. This could lead to further bugs and the introduction of weaknesses.

## Cómo evitarlo

- Remove unused variables from the code.
