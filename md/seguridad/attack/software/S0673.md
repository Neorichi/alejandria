# S0673 DarkWatchman (Malware)

**Malware de MITRE ATT&CK** S0673.

- **Plataformas:** Windows

DarkWatchman is a lightweight JavaScript-based remote access tool (RAT) that avoids file operations; it was first observed in November 2021.
