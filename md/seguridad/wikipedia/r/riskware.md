# Riskware

**Riskware**, una combinación de las palabras «riesgo» y «software», es un término utilizado para describir el software cuya instalación y ejecución supone un riesgo potencial para el ordenador anfitrión. A menudo, programas relativamente normales pueden entrar en la categoría de riskware, ya que algunas aplicaciones pueden modificarse para otros fines y utilizarse en contra del usuario o propietario del ordenador.

 Ejemplos
Aunque hay una gran variedad de programas que pueden considerarse riskware, un ejemplo común es el software de escritorio remoto. Este tipo de software tiene fines legítimos, como cuando se utiliza para la asistencia técnica remota, pero también podría ser utilizado por un usuario no autorizado con fines maliciosos.
