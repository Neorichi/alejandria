# CWE-1292: Incorrect Conversion of Security Identifiers

**Tipo de fallo de software CWE-1292** (Base).

The product implements a conversion mechanism to map certain bus-transaction signals to security identifiers, but this conversion between protocols is incorrectly implemented.

- **Es un caso de:** [CWE-1294](/seguridad/cwe/CWE-1294.md)

## Consecuencias

- Modify Memory: An untrusted agent may gain unauthorized access to an asset

## Cómo evitarlo

- Security identifier decoders must be reviewed for design inconsistency and common weaknesses.
- Access and programming flows must be tested in pre-silicon and post-silicon testing.
