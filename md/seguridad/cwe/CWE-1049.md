# CWE-1049: Excessive Data Query Operations in a Large Data Table

**Tipo de fallo de software CWE-1049** (Base).

The product performs a data query with a large number of joins and sub-queries on a large data table.

- **Es un caso de:** [CWE-1176](/seguridad/cwe/CWE-1176.md)

## Consecuencias

- Reduce Performance: This issue can make the product perform more slowly. If the relevant code is reachable by an attacker, then this performance problem might introduce a vulnerability.
