# CWE-657: Violation of Secure Design Principles

**Tipo de fallo de software CWE-657** (Class).

The product violates well-established principles for secure design.

- **Es un caso de:** [CWE-710](/seguridad/cwe/CWE-710.md)

## Consecuencias

- Varies by Context: This can introduce resultant weaknesses or make it easier for developers to introduce related weaknesses during implementation.
- Reduce Maintainability: Because code is centered around design, it can be resource-intensive to fix design problems.
