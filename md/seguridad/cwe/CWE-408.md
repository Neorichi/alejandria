# CWE-408: Incorrect Behavior Order: Early Amplification

**Tipo de fallo de software CWE-408** (Base).

The product allows an entity to perform a legitimate but expensive operation before authentication or authorization has taken place.

- **Es un caso de:** [CWE-405](/seguridad/cwe/CWE-405.md), [CWE-696](/seguridad/cwe/CWE-696.md)

## Consecuencias

- DoS: Amplification: System resources, CPU and memory, can be quickly consumed. This can lead to poor system performance or system crash.
