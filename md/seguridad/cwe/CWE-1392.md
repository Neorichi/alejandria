# CWE-1392: Use of Default Credentials

**Tipo de fallo de software CWE-1392** (Base).

The product uses default credentials (such as passwords or cryptographic keys) for potentially critical functionality.

- **Es un caso de:** [CWE-1391](/seguridad/cwe/CWE-1391.md)

## Consecuencias

- Gain Privileges or Assume Identity: If admins do not change the defaults, it is easier for attackers to bypass authentication quickly across multiple organizations.

## Cómo evitarlo

- Prohibit use of default, hard-coded, or other values that do not vary for each installation of the product - especially for separate organizations.
- Force the administrator to change the credential upon installation.
- The product administrator could change the defaults upon installation or during operation.
