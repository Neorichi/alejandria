# S0586 TAINTEDSCRIBE (Malware)

**Malware de MITRE ATT&CK** S0586.

- **Plataformas:** Windows

TAINTEDSCRIBE is a fully-featured beaconing implant integrated with command modules used by Lazarus Group. It was first reported in May 2020.
