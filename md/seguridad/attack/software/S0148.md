# S0148 RTM (Malware)

**Malware de MITRE ATT&CK** S0148.

- **Plataformas:** Windows

RTM is custom malware written in Delphi. It is used by the group of the same name (RTM). Newer versions of the malware have been reported publicly as Redaman.
