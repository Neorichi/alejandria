# CWE-1471: Insufficiently Controlled Parser Differential

**Tipo de fallo de software CWE-1471** (Class).

The product uses a common specification or format that is shared between multiple components or entities, but the components have different parsers that can interpret the same input in different, security-relevant ways.

- **Es un caso de:** [CWE-436](/seguridad/cwe/CWE-436.md)

## Consecuencias

- Gain Privileges or Assume Identity: If an input is analyzed and/or processed by multiple components in security-related situations - such as analyzing headers or comparing identifiers - then a parser differential could lead to incorrect security decisions.

## Cómo evitarlo

- If possible, ensure that the same parser is used by each component.
