# CWE-546: Suspicious Comment

**Tipo de fallo de software CWE-546** (Base).

The code contains comments that suggest the presence of bugs, incomplete functionality, or weaknesses.

- **Es un caso de:** [CWE-1078](/seguridad/cwe/CWE-1078.md)

## Consecuencias

- Quality Degradation: Suspicious comments could be an indication that there are problems in the source code that may need to be fixed and is an indication of poor quality. This could lead to further bugs and the introduction of weaknesses.

## Cómo evitarlo

- Remove comments that suggest the presence of bugs, incomplete functionality, or weaknesses, before deploying the application.
