# CWE-499: Serializable Class Containing Sensitive Data

**Tipo de fallo de software CWE-499** (Variant).

The code contains a class with sensitive data, but the class does not explicitly deny serialization.

- **Es un caso de:** [CWE-668](/seguridad/cwe/CWE-668.md)

## Consecuencias

- Read Application Data: Classes that do not explicitly deny serialization can be serialized by any other class, which can then in turn use the data stored inside it. The data can be accessed by serializing the class through another class. Alternately, an attacker can write out the class to a byte stream, then extract the important data from it.

## Cómo evitarlo

- In Java, explicitly define final writeObject() to prevent serialization. This is the recommended solution. Define the writeObject() function to throw an exception explicitly denying serialization.
- Make sure to prevent serialization of your objects.
