# CWE-498: Cloneable Class Containing Sensitive Information

**Tipo de fallo de software CWE-498** (Variant).

The code contains a class with sensitive data, but the class is cloneable. The data can then be accessed by cloning the class.

- **Es un caso de:** [CWE-668](/seguridad/cwe/CWE-668.md)

## Consecuencias

- Bypass Protection Mechanism: A class that does not explicitly deny cloning can be cloned by any other class without running the constructor. Cloneable classes are effectively open classes, since data cannot be hidden in the. This is also dangerous since the constructor may perform security-related checks. By allowing the object to be cloned, those checks may be bypassed.

## Cómo evitarlo

- If you do make your classes clonable, ensure that your clone method is final and throw super.clone().
