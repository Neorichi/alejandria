# CWE-842: Placement of User into Incorrect Group

**Tipo de fallo de software CWE-842** (Base).

The product or the administrator places a user into an incorrect group.

- **Es un caso de:** [CWE-286](/seguridad/cwe/CWE-286.md)

## Consecuencias

- Gain Privileges or Assume Identity: If the incorrect group has more access or privileges than the intended group, the user might be able to bypass intended security policy to access unexpected resources or perform unexpected actions. The access-control system might not be able to detect malicious usage of this group membership.
