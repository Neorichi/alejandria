# CWE-547: Use of Hard-coded, Security-relevant Constants

**Tipo de fallo de software CWE-547** (Base).

The product uses hard-coded constants instead of symbolic names for security-critical values, which increases the likelihood of mistakes during code maintenance or security policy change.

- **Es un caso de:** [CWE-1078](/seguridad/cwe/CWE-1078.md)

## Consecuencias

- Varies by Context: The existence of hardcoded constants could cause unexpected behavior and the introduction of weaknesses during code maintenance or when making changes to the code if all occurrences are not modified. The use of hardcoded constants is an indication of poor quality. In addition, these hard-coded values may become available to attackers if the code is ever disclosed.

## Cómo evitarlo

- Avoid using hard-coded constants. Configuration files offer a more flexible solution.
