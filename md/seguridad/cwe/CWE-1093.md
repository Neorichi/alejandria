# CWE-1093: Excessively Complex Data Representation

**Tipo de fallo de software CWE-1093** (Class).

The product uses an unnecessarily complex internal representation for its data structures or interrelationships between those structures.

- **Es un caso de:** [CWE-710](/seguridad/cwe/CWE-710.md)

## Consecuencias

- Reduce Maintainability: This issue makes it more difficult to understand or maintain the product, which indirectly affects security by making it more difficult or time-consuming to find and/or fix vulnerabilities. It also might make it easier to introduce vulnerabilities.
- Reduce Performance
