# CWE-832: Unlock of a Resource that is not Locked

**Tipo de fallo de software CWE-832** (Base).

The product attempts to unlock a resource that is not locked.

- **Es un caso de:** [CWE-667](/seguridad/cwe/CWE-667.md)

## Consecuencias

- DoS: Crash, Exit, or Restart: Depending on the locking functionality, an unlock of a non-locked resource might corrupt the state of the product, possibly including denial of service, memory corruption, or other modification to the resource (or its associated metadata that is used for tracking locks). In some cases, an unlock operation might not have any adverse effects.
