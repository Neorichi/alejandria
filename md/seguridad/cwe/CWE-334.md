# CWE-334: Small Space of Random Values

**Tipo de fallo de software CWE-334** (Base).

The number of possible random values is smaller than needed by the product, making it more susceptible to brute force attacks.

- **Es un caso de:** [CWE-330](/seguridad/cwe/CWE-330.md)

## Consecuencias

- Bypass Protection Mechanism: An attacker could easily guess the values used. This could lead to unauthorized access to a system if the seed is used for authentication and authorization.

## Cómo evitarlo

- Use products or modules that conform to FIPS 140-2 [REF-267] to avoid obvious entropy problems. Consult FIPS 140-2 Annex C ("Approved Random Number Generators").
