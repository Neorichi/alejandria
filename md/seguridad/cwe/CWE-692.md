# CWE-692: Incomplete Denylist to Cross-Site Scripting

**Tipo de fallo de software CWE-692** (Compound).

The product uses a denylist-based protection mechanism to defend against XSS attacks, but the denylist is incomplete.

- **Es un caso de:** [CWE-184](/seguridad/cwe/CWE-184.md)

## Consecuencias

- Execute Unauthorized Code or Commands: Attackers could create XSS variants that still work. While XSS might seem simple to prevent, web browsers vary so widely in how they parse web pages, that a denylist cannot keep track of all the variations. The "XSS Cheat Sheet" [REF-714] contains a large number of attacks that are intended to bypass incomplete denylists.
