# CWE-578: EJB Bad Practices: Use of Class Loader

**Tipo de fallo de software CWE-578** (Variant).

The product violates the Enterprise JavaBeans (EJB) specification by using the class loader.

- **Es un caso de:** [CWE-695](/seguridad/cwe/CWE-695.md)

## Consecuencias

- Execute Unauthorized Code or Commands: The specification [REF-1543] justifies this requirement in the following way: "These functions are reserved for the EJB container. Allowing the enterprise bean to use these functions could compromise security and decrease the container's ability to properly manage the runtime environment."

## Cómo evitarlo

- Do not use the Class Loader when writing EJBs.
