# CWE-600: Uncaught Exception in Servlet

**Tipo de fallo de software CWE-600** (Variant).

The Servlet does not catch all exceptions.

- **Es un caso de:** [CWE-248](/seguridad/cwe/CWE-248.md)

## Consecuencias

- Read Application Data: When a Servlet throws an exception, the default error response the Servlet container sends back to the user typically includes debugging information. This information is of great value to an attacker. For example, a stack trace might show the attacker a malformed SQL query string, the type of database being used, and the version of the application container. This information enables the attacker to target known vulnerabilities in these components.

## Cómo evitarlo

- Implement Exception blocks to handle all types of Exceptions.
