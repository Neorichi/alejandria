# CWE-409: Improper Handling of Highly Compressed Data (Data Amplification)

**Tipo de fallo de software CWE-409** (Base).

The product does not handle or incorrectly handles a compressed input with a very high compression ratio that produces a large output.

- **Es un caso de:** [CWE-405](/seguridad/cwe/CWE-405.md)

## Consecuencias

- DoS: Amplification: System resources, CPU and memory, can be quickly consumed. This can lead to poor system performance or system crash.
