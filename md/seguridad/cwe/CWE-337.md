# CWE-337: Predictable Seed in Pseudo-Random Number Generator (PRNG)

**Tipo de fallo de software CWE-337** (Variant).

A Pseudo-Random Number Generator (PRNG) is initialized from a predictable seed, such as the process ID or system time.

- **Es un caso de:** [CWE-335](/seguridad/cwe/CWE-335.md)

## Consecuencias

- Bypass Protection Mechanism: The use of predictable seeds significantly reduces the number of possible seeds that an attacker would need to test in order to predict which random numbers will be generated by the PRNG. A protection mechanism that depends on a PRNG could be compromised.

## Cómo evitarlo

- Use non-predictable inputs for seed generation.
- Use products or modules that conform to FIPS 140-2 [REF-267] to avoid obvious entropy problems, or use the more recent FIPS 140-3 [REF-1192] if possible.
- Use a PRNG that periodically re-seeds itself using input from high-quality sources, such as hardware devices with high entropy. However, do not re-seed too frequently, or else the entropy source might block.
