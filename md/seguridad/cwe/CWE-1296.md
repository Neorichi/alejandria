# CWE-1296: Incorrect Chaining or Granularity of Debug Components

**Tipo de fallo de software CWE-1296** (Base).

The product's debug components contain incorrect chaining or granularity of debug components.

Logic errors during design or synthesis could misconfigure the interconnection of the debug components, which could allow unintended access permissions.

- **Es un caso de:** [CWE-284](/seguridad/cwe/CWE-284.md)

## Consecuencias

- Gain Privileges or Assume Identity: Depending on the access to debug component(s) erroneously granted, an attacker could use the debug component to gain additional understanding about the system to further an attack and/or execute other commands. This could compromise any security property, including the ones listed above.

## Cómo evitarlo

- Ensure that debug components are properly chained and their granularity is maintained at different authentication levels.
