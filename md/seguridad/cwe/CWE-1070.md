# CWE-1070: Serializable Data Element Containing non-Serializable Item Elements

**Tipo de fallo de software CWE-1070** (Base).

The product contains a serializable, storable data element such as a field or member, but the data element contains member elements that are not serializable.

- **Es un caso de:** [CWE-1076](/seguridad/cwe/CWE-1076.md)

## Consecuencias

- Reduce Reliability: This issue can prevent the product from running reliably. If the relevant code is reachable by an attacker, then this reliability problem might introduce a vulnerability.
