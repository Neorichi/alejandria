# CWE-914: Improper Control of Dynamically-Identified Variables

**Tipo de fallo de software CWE-914** (Base).

The product does not properly restrict reading from or writing to dynamically-identified variables.

- **Es un caso de:** [CWE-99](/seguridad/cwe/CWE-99.md), [CWE-913](/seguridad/cwe/CWE-913.md)

## Consecuencias

- Modify Application Data: An attacker could modify sensitive data or critical program variables.
- Execute Unauthorized Code or Commands
- Varies by Context

## Cómo evitarlo

- For any externally-influenced input, check the input against an allowlist of internal program variables that are allowed to be modified.
- Refactor the code so that internal program variables do not need to be dynamically identified.
