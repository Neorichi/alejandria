# CWE-336: Same Seed in Pseudo-Random Number Generator (PRNG)

**Tipo de fallo de software CWE-336** (Variant).

The product uses a Pseudo-Random Number Generator (PRNG) that uses the same seed each time the product is initialized.

- **Es un caso de:** [CWE-335](/seguridad/cwe/CWE-335.md)

## Consecuencias

- Varies by Context: Given the deterministic nature of PRNGs, using the same seed for each initialization will lead to the same output in the same order. If an attacker can guess (or knows) the seed, then they may be able to determine the random numbers that will be produced from the PRNG.

## Cómo evitarlo

- Do not reuse PRNG seeds. Consider a PRNG that periodically re-seeds itself as needed from a high quality pseudo-random output, such as hardware devices.
- Use products or modules that conform to FIPS 140-2 [REF-267] to avoid obvious entropy problems, or use the more recent FIPS 140-3 [REF-1192] if possible.
