# CWE-313: Cleartext Storage in a File or on Disk

**Tipo de fallo de software CWE-313** (Variant).

The product stores sensitive information in cleartext in a file, or on disk.

- **Es un caso de:** [CWE-312](/seguridad/cwe/CWE-312.md)

## Consecuencias

- Read Application Data: The sensitive information could be read by attackers with access to the file, or with physical or administrator access to the raw disk. Even if the information is encoded in a way that is not human-readable, certain techniques could determine which encoding is being used, then decode the information.
