# CWE-1071: Empty Code Block

**Tipo de fallo de software CWE-1071** (Base).

The source code contains a block that does not contain any code, i.e., the block is empty.

- **Es un caso de:** [CWE-1164](/seguridad/cwe/CWE-1164.md)

## Consecuencias

- Reduce Reliability: The lack of any behavior within the block might violate a convention or API in such a way that it is an error. It could indicate a situation in which some kind of action should be taken.
