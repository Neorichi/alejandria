# S0670 WarzoneRAT (Malware)

**Malware de MITRE ATT&CK** S0670.

- **Plataformas:** Windows

WarzoneRAT is a malware-as-a-service remote access tool (RAT) written in C++ that has been publicly available for purchase since at least late 2018.
