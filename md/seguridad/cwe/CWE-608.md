# CWE-608: Struts: Non-private Field in ActionForm Class

**Tipo de fallo de software CWE-608** (Variant).

The product uses an ActionForm class that contains a field that has not been declared private.

- **Es un caso de:** [CWE-732](/seguridad/cwe/CWE-732.md)

## Consecuencias

- Modify Application Data: A field that is not declared private can be accessed without using a setter or getter.

## Cómo evitarlo

- Make all fields private. Use getter to get the value of the field. Setter should be used only by the framework; setting an action form field from other actions is bad practice and should be avoided.
