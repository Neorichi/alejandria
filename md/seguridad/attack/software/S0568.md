# S0568 EVILNUM (Malware)

**Malware de MITRE ATT&CK** S0568.

- **Plataformas:** Windows

EVILNUM is fully capable backdoor that was first identified in 2018. EVILNUM is used by the APT group Evilnum which has the same name.
