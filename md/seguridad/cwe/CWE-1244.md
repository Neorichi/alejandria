# CWE-1244: Internal Asset Exposed to Unsafe Debug Access Level or State

**Tipo de fallo de software CWE-1244** (Base).

The product uses physical debug or test interfaces with support for multiple access levels, but it assigns the wrong debug access level to an internal asset, providing unintended access to the asset from untrusted debug agents.

- **Es un caso de:** [CWE-863](/seguridad/cwe/CWE-863.md)

## Consecuencias

- Read Memory: If a protection mechanism does not ensure that internal assets have the correct debug access level during each boot stage or change in system state, an attacker could obtain sensitive information from the internal asset using a debugger.
- Modify Memory
- Gain Privileges or Assume Identity

## Cómo evitarlo

- For security-sensitive assets accessible over debug/test interfaces, only allow trusted agents.
- Apply blinding [REF-1219] or masking techniques in strategic areas.
- Add shielding or tamper-resistant protections to the device, which increases the difficulty and cost for accessing debug/test interfaces.
