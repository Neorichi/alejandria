# CWE-619: Dangling Database Cursor

**Tipo de fallo de software CWE-619** (Base).

The product does not close a database cursor properly, leaving the cursor "dangling."

- **Es un caso de:** [CWE-402](/seguridad/cwe/CWE-402.md)

## Consecuencias

- Read Application Data: The cursor could become accessible to other users while retaining the same privileges that were originally assigned. The impact of the issue depends on the cursor's role, but SQL injection attacks are commonly possible.

## Cómo evitarlo

- Close cursors immediately after access to them is complete. Ensure that you close cursors if exceptions occur.
