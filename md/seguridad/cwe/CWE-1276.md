# CWE-1276: Hardware Child Block Incorrectly Connected to Parent System

**Tipo de fallo de software CWE-1276** (Base).

Signals between a hardware IP and the parent system design are incorrectly connected.

- **Es un caso de:** [CWE-284](/seguridad/cwe/CWE-284.md)

## Consecuencias

- Varies by Context: This may cause security risks. For example, if the IP should only be reset by a system-wide hard reset, but instead the reset input is connected to a software-triggered debug mode reset (which is also asserted during a hard reset), integrity of data inside the IP can be violated.

## Cómo evitarlo

- System-level verification may be used to ensure that components are correctly connected and that design security requirements are not violated due to interactions between various IP blocks.
