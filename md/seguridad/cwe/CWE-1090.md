# CWE-1090: Method Containing Access of a Member Element from Another Class

**Tipo de fallo de software CWE-1090** (Base).

A method for a class performs an operation that directly accesses a member element from another class.

- **Es un caso de:** [CWE-1061](/seguridad/cwe/CWE-1061.md)

## Consecuencias

- Reduce Maintainability: This issue suggests poor encapsulation and makes it more difficult to understand and maintain the product, which indirectly affects security by making it more difficult or time-consuming to find and/or fix vulnerabilities. It also might make it easier to introduce vulnerabilities.
