# CWE-392: Missing Report of Error Condition

**Tipo de fallo de software CWE-392** (Base).

The product encounters an error but does not provide a status code or return value to indicate that an error has occurred.

- **Es un caso de:** [CWE-755](/seguridad/cwe/CWE-755.md), [CWE-684](/seguridad/cwe/CWE-684.md), [CWE-703](/seguridad/cwe/CWE-703.md)

## Consecuencias

- Varies by Context: Errors that are not properly reported could place the system in an unexpected state that could lead to unintended behaviors.
