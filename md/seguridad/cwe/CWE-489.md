# CWE-489: Active Debug Code

**Tipo de fallo de software CWE-489** (Base).

The product is released with debugging code still enabled or active.

- **Es un caso de:** [CWE-710](/seguridad/cwe/CWE-710.md)

## Consecuencias

- Bypass Protection Mechanism: Active debug code can create unintended entry points or expose sensitive information. The severity of the exposed debug code will depend on the particular instance. At the least, it will give an attacker sensitive information about the settings and mechanics of web applications on the server. At worst, as is often the case, the debug code will allow an attacker complete control over the web application and server, as well as confidential information that is accessed by either of these.

## Cómo evitarlo

- Remove debug code before deploying the application.
