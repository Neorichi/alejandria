# CWE-756: Missing Custom Error Page

**Tipo de fallo de software CWE-756** (Base).

The product does not return custom error pages to the user, possibly exposing sensitive information.

- **Es un caso de:** [CWE-755](/seguridad/cwe/CWE-755.md)

## Consecuencias

- Read Application Data: Attackers can leverage the additional information provided by a default error page to mount attacks targeted on the framework, database, or other resources used by the application.
