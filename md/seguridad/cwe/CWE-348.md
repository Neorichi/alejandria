# CWE-348: Use of Less Trusted Source

**Tipo de fallo de software CWE-348** (Base).

The product has two different sources of the same data or information, but it uses the source that has less support for verification, is less trusted, or is less resistant to attack.

- **Es un caso de:** [CWE-345](/seguridad/cwe/CWE-345.md)

## Consecuencias

- Bypass Protection Mechanism: An attacker could utilize the untrusted data source to bypass protection mechanisms and gain access to sensitive data.
