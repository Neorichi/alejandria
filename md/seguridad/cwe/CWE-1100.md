# CWE-1100: Insufficient Isolation of System-Dependent Functions

**Tipo de fallo de software CWE-1100** (Base).

The product or code does not isolate system-dependent functionality into separate standalone modules.

- **Es un caso de:** [CWE-1061](/seguridad/cwe/CWE-1061.md)

## Consecuencias

- Reduce Maintainability: This issue makes it more difficult to maintain and/or port the product, which indirectly affects security by making it more difficult or time-consuming to find and/or fix vulnerabilities. It also might make it easier to introduce vulnerabilities.
