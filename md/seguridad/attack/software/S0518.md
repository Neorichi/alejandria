# S0518 PolyglotDuke (Malware)

**Malware de MITRE ATT&CK** S0518.

- **Plataformas:** Windows

PolyglotDuke is a downloader that has been used by APT29 since at least 2013. PolyglotDuke has been used to drop MiniDuke.
