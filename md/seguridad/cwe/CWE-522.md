# CWE-522: Insufficiently Protected Credentials

**Tipo de fallo de software CWE-522** (Class).

The product transmits or stores authentication credentials, but it uses an insecure method that is susceptible to unauthorized interception and/or retrieval.

- **Es un caso de:** [CWE-1390](/seguridad/cwe/CWE-1390.md), [CWE-287](/seguridad/cwe/CWE-287.md), [CWE-668](/seguridad/cwe/CWE-668.md)

## Consecuencias

- Gain Privileges or Assume Identity: An attacker could gain access to user accounts and access sensitive data used by the user accounts.

## Cómo evitarlo

- Use an appropriate security mechanism to protect the credentials.
- Make appropriate use of cryptography to protect the credentials.
- Use industry standards to protect the credentials (e.g. LDAP, keystore, etc.).
