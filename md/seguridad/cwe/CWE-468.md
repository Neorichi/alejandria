# CWE-468: Incorrect Pointer Scaling

**Tipo de fallo de software CWE-468** (Base).

In C and C++, one may often accidentally refer to the wrong memory due to the semantics of when math operations are implicitly scaled.

- **Es un caso de:** [CWE-682](/seguridad/cwe/CWE-682.md)

## Consecuencias

- Read Memory: Incorrect pointer scaling will often result in buffer overflow conditions. Confidentiality can be compromised if the weakness is in the context of a buffer over-read or under-read.

## Cómo evitarlo

- Use a platform with high-level memory abstractions.
- Always use array indexing instead of direct pointer manipulation.
- Use technologies for preventing buffer overflows.
