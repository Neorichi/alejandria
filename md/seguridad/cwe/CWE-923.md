# CWE-923: Improper Restriction of Communication Channel to Intended Endpoints

**Tipo de fallo de software CWE-923** (Class).

The product establishes a communication channel to (or from) an endpoint for privileged or protected operations, but it does not properly ensure that it is communicating with the correct endpoint.

While this issue frequently involves authentication between network-based clients and servers, other types of communication channels and endpoints can have this weakness.

- **Es un caso de:** [CWE-284](/seguridad/cwe/CWE-284.md)

## Consecuencias

- Gain Privileges or Assume Identity: Attackers might be able to spoof the intended endpoint from a different system or process, thus gaining the same level of access as the intended endpoint. The attacker could gains all the privileges that were intended for the original endpoint.
