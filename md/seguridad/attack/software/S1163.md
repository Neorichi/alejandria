# S1163 SnappyTCP (Malware)

**Malware de MITRE ATT&CK** S1163.

- **Plataformas:** Linux

SnappyTCP is a web shell used by Sea Turtle between 2021 and 2023 against multiple victims. SnappyTCP appears to be based on a public GitHub project that has since been removed from the code-sharing site. SnappyTCP includes a simple reverse TCP shell for Linux and Unix environments with basic command and control capabilities.
