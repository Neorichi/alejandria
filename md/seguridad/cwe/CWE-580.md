# CWE-580: clone() Method Without super.clone()

**Tipo de fallo de software CWE-580** (Variant).

The product contains a clone() method that does not call super.clone() to obtain the new object.

- **Es un caso de:** [CWE-664](/seguridad/cwe/CWE-664.md), [CWE-573](/seguridad/cwe/CWE-573.md)

## Consecuencias

- Unexpected State: If a class does not follow this convention, a subclass's clone() method will return an object of the wrong type.

## Cómo evitarlo

- All implementations of clone() should obtain the new object by calling super.clone().
- In some cases, you can eliminate the clone method altogether and use copy constructors.
