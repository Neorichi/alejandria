# CWE-321: Use of Hard-coded Cryptographic Key

**Tipo de fallo de software CWE-321** (Variant).

The product uses a hard-coded, unchangeable cryptographic key.

- **Es un caso de:** [CWE-798](/seguridad/cwe/CWE-798.md)

## Consecuencias

- Bypass Protection Mechanism: If hard-coded cryptographic keys are used, it is almost certain that malicious users will gain access through the account in question. The use of a hard-coded cryptographic key significantly increases the possibility that encrypted data may be recovered.

## Cómo evitarlo

- Prevention schemes mirror that of hard-coded password storage.
