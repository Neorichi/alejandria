# CWE-1328: Security Version Number Mutable to Older Versions

**Tipo de fallo de software CWE-1328** (Base).

The security version number in the hardware product is mutable, resulting in the ability to downgrade (roll-back) the boot firmware to vulnerable code versions.

- **Es un caso de:** [CWE-285](/seguridad/cwe/CWE-285.md)

## Consecuencias

- Other: If the security version number is modifiable by an adversary, this allows attacks like downgrading to a previous version that contains vulnerabilities. Once downgraded to a previous version, an adversary can launch exploits on the SoC and thus compromise the security of the SoC. These downgrade attacks are also referred to as roll-back attacks.
- Other: An adversary could prevent upgrades, casing a denial of service.

## Cómo evitarlo

- The security version number must be stored securely and persistently across power-on resets. When architecting the system, security version data should be designated for storage in registers that are either read-only or have access controls that prevent modification by an untrusted agent.
- During implementation and test, security version data should be demonstrated to be read-only and access controls should be validated.
