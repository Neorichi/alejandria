# CWE-821: Incorrect Synchronization

**Tipo de fallo de software CWE-821** (Base).

The product utilizes a shared resource in a concurrent manner, but it does not correctly synchronize access to the resource.

- **Es un caso de:** [CWE-662](/seguridad/cwe/CWE-662.md)

## Consecuencias

- Modify Application Data: If access to a shared resource is not correctly synchronized, then the resource may not be in a state that is expected by the product. This might lead to unexpected or insecure behaviors, especially if an attacker can influence the shared resource.
