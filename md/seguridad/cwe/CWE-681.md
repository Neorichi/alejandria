# CWE-681: Incorrect Conversion between Numeric Types

**Tipo de fallo de software CWE-681** (Base).

When converting from one data type to another, such as long to integer, data can be omitted or translated in a way that produces unexpected values. If the resulting values are used in a sensitive context, then dangerous behaviors may occur.

- **Es un caso de:** [CWE-704](/seguridad/cwe/CWE-704.md)

## Consecuencias

- Unexpected State: The program could wind up using the wrong number and generate incorrect results. If the number is used to allocate resources or make a security decision, then this could introduce a vulnerability.

## Cómo evitarlo

- Avoid making conversion between numeric types. Always check for the allowed ranges.
