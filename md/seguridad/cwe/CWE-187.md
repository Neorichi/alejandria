# CWE-187: Partial String Comparison

**Tipo de fallo de software CWE-187** (Variant).

The product performs a string comparison that only examines a portion of the string before determining whether there is a match.

- **Es un caso de:** [CWE-1023](/seguridad/cwe/CWE-1023.md)

## Consecuencias

- Alter Execution Logic: An attacker might succeed in authentication by providing a small password that matches the associated portion of the larger, correct password.

## Cómo evitarlo

- Thoroughly test the comparison scheme before deploying code into production. Perform positive testing as well as negative testing.
