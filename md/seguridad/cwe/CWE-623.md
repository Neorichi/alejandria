# CWE-623: Unsafe ActiveX Control Marked Safe For Scripting

**Tipo de fallo de software CWE-623** (Variant).

The product includes an ActiveX control that is intended for restricted use, but the control has been marked as safe-for-scripting.

- **Es un caso de:** [CWE-267](/seguridad/cwe/CWE-267.md)

## Consecuencias

- Execute Unauthorized Code or Commands: Attackers may be able to use dangerous functionality via a web page that accesses the control, which can lead to different resultant vulnerabilities, depending on the control's behavior.

## Cómo evitarlo

- During development, do not mark it as safe for scripting.
- After distribution, you can set the kill bit for the control so that it is not accessible from Internet Explorer.
