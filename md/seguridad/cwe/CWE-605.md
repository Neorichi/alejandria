# CWE-605: Multiple Binds to the Same Port

**Tipo de fallo de software CWE-605** (Variant).

When multiple sockets are allowed to bind to the same port, other services on that port may be stolen or spoofed.

- **Es un caso de:** [CWE-675](/seguridad/cwe/CWE-675.md), [CWE-666](/seguridad/cwe/CWE-666.md)

## Consecuencias

- Read Application Data: An attacker could access the TCP connection or UDP packets for a different service. Packets from a variety of network services may be stolen or the services spoofed.

## Cómo evitarlo

- Restrict server socket address to known local addresses.
