# S0632 GrimAgent (Malware)

**Malware de MITRE ATT&CK** S0632.

- **Plataformas:** Windows

GrimAgent is a backdoor that has been used before the deployment of Ryuk ransomware since at least 2020; it is likely used by FIN6 and Wizard Spider.
