# S1013 ZxxZ (Malware)

**Malware de MITRE ATT&CK** S1013.

- **Plataformas:** Windows

ZxxZ is a trojan written in Visual C++ that has been used by BITTER since at least August 2021, including against Bangladeshi government personnel.
