# CWE-1233: Security-Sensitive Hardware Controls with Missing Lock Bit Protection

**Tipo de fallo de software CWE-1233** (Base).

The product uses a register lock bit protection mechanism, but it does not ensure that the lock bit prevents modification of system registers or controls that perform changes to important hardware system configuration.

- **Es un caso de:** [CWE-284](/seguridad/cwe/CWE-284.md), [CWE-667](/seguridad/cwe/CWE-667.md)

## Consecuencias

- Modify Memory: System Configuration protected by the lock bit can be modified even when the lock is set. If the lock bit does not effectively write-protect all system registers or controls that could modify the protected system configuration, then an adversary may be able to use software to access the registers/controls and modify the protected hardware configuration.

## Cómo evitarlo

- Security lock bit protections must be reviewed for design inconsistency and common weaknesses. Security lock programming flow and lock properties must be tested in pre-silicon and post-silicon testing.
