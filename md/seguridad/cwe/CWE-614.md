# CWE-614: Sensitive Cookie in HTTPS Session Without 'Secure' Attribute

**Tipo de fallo de software CWE-614** (Variant).

The Secure attribute for sensitive cookies in HTTPS sessions is not set.

- **Es un caso de:** [CWE-319](/seguridad/cwe/CWE-319.md)

## Consecuencias

- Read Application Data: Omitting the secure flag makes it possible for the user agent to send the cookies in plaintext over an HTTP session.

## Cómo evitarlo

- Always set the secure attribute when the cookie should be sent via HTTPS only.
