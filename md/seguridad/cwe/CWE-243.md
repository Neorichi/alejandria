# CWE-243: Creation of chroot Jail Without Changing Working Directory

**Tipo de fallo de software CWE-243** (Variant).

The product uses the chroot() system call to create a jail, but it does not change the working directory afterward.

- **Es un caso de:** [CWE-573](/seguridad/cwe/CWE-573.md), [CWE-669](/seguridad/cwe/CWE-669.md)

## Consecuencias

- Read Files or Directories: If the working directory is not changed after the chroot() call, relative paths may still refer to file system resources outside of the jail. Attackers may be able to read or write to files outside of the jail.
