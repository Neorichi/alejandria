# CWE-644: Improper Neutralization of HTTP Headers for Scripting Syntax

**Tipo de fallo de software CWE-644** (Variant).

The product does not neutralize or incorrectly neutralizes web scripting syntax in HTTP headers that can be used by web browser components that can process raw headers, such as Flash.

- **Es un caso de:** [CWE-116](/seguridad/cwe/CWE-116.md)

## Consecuencias

- Execute Unauthorized Code or Commands: The header may contain a script that will get executed in the client's browser context, potentially resulting in a cross site scripting vulnerability or possibly an HTTP response splitting attack.
- Read Application Data: Attackers may be able to obtain sensitive information.

## Cómo evitarlo

- Carefully control data that is being placed both in HTTP response headers and in the HTTP response body to ensure that no scripting syntax is present, taking various encodings into account. Perform output validation in order to filter/escape/encode unsafe data that is being passed from the server in an HTTP response header.
- Disable script execution functionality in the clients' browser.
